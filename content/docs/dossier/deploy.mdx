Dossier 是静态浏览器应用。部署到 SIREN 时，只需要把构建后的 `index.html`、`editor.js`、`editor.css`、`report.md` 和 `assets/` 放到控制主机上的 Dossier 目录。

## SIREN WebUI 部署

默认配置从 `/opt/siren/dossier` 读取 Dossier 编辑器文件，并把 `/opt/siren/dossier/report.md` 作为左侧 Dossier 入口的默认报告。

<Steps>
<Step>

### 构建 Dossier

```bash title="Dossier 项目目录"
npm install
npm run build
```

</Step>
<Step>

### 复制到控制主机

```bash title="控制主机"
sudo mkdir -p /opt/siren/dossier
sudo rsync -av index.html editor.css editor.js report.md assets/ /opt/siren/dossier/
```

</Step>
<Step>

### 配置并重启 SIREN

```yaml title="server_config.yaml"
webui:
  dossierDir: /opt/siren/dossier
```

修改后重启 `siren_server`，再从 WebUI 左侧点击 **Dossier**。

</Step>
</Steps>

<Callout title="不要复制到 WebUI dist" type="warn">
  不要把 Dossier 文件复制到 `internal/server/webui/frontend/dist` 或 `frontend/public`。Dossier 应作为外部静态目录部署，否则会被打包进 `siren_server` 二进制。
</Callout>

## 本地离线使用

在 Dossier 文件目录启动一个本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

页面默认加载同目录的 `report.md`。如需打开同源目录下的其他报告，可以使用：

```text
http://localhost:8000/?md=case.md
```

## 打包交付

Dossier 项目支持生成本地交付包：

```bash title="Dossier 项目目录"
make dist
```

生成的压缩包包含 `index.html`、`editor.js`、`editor.css`、`report.md`、`assets/` 和本地启动脚本，适合交给报告作者离线编辑。

## 反向代理

如果 WebUI 通过 Nginx 或 Caddy 暴露，建议把同一域名完整转发到 SIREN WebUI 端口，包括 `/dossier/`、`/api/reports/*` 和 `/api/dossier/status`。

只代理 `/dossier/` 会导致编辑器页面可访问，但保存正文、粘贴图片或读取默认报告失败。`/api/dossier/status` 用于探测 `webui.dossierDir` 是否已正确配置并可用，未一并转发会导致编辑器误判 Dossier 不可用。
