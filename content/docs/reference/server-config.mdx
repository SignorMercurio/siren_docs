本页列出 `siren_server` 读取的全部配置键、命令行参数和环境变量。安装步骤见 [安装服务端](/server)，依赖缺失的影响见 [前置条件与凭证](/server/prerequisites)。

## 加载规则

### 配置文件位置

1. `-c` / `--config` 指定的文件。
2. 未指定时，依次在当前工作目录和 `config/` 子目录中查找 `server_config.yaml`（也接受 `.yml` 等同名的其他格式）。

找不到或无法解析配置文件时服务端直接退出。`siren_server user` 等子命令读取同一份配置，也要在工作目录中执行。

相对路径（`cert`、`key`、`webui.userDBPath`、`webui.dossierDir`、`webui.projectsBaseDir`）按启动时的工作目录解析，而非配置文件所在目录，见 [服务端数据](/upgrade#服务端数据)。

### 优先级

从高到低：

1. 显式传入的 [命令行参数](#命令行参数)。
2. 与键名大写形式同名的环境变量，只对顶层键有意义：`LISTEN`、`PORT`、`CERT`、`KEY` 覆盖 `listen`、`port`、`cert`、`key`。服务环境或 `.env` 中恰好有 `PORT` 时，服务端会监听这个端口。
3. 配置文件。
4. 内置默认值（下文各表的“默认值”列）。

### 生效时机

配置只在启动时读取一次，修改任何键都要重启服务端；重启会清空内存状态，见 [重启的影响](/upgrade#重启的影响)。

重新运行安装脚本或 `siren_server upgrade` 不会改动已有的 `server_config.yaml`，旧配置中缺失的新键使用内置默认值。

## 命令行参数

| 参数 | 对应键 | 参数默认值 |
| --- | --- | --- |
| `-c`, `--config` | 无（配置文件路径） | 按 [配置文件位置](#配置文件位置) 查找 |
| `-l`, `--listen` | `listen` | `0.0.0.0` |
| `-p`, `--port` | `port` | `443` |
| `--cert` | `cert` | `certs/cert.pem` |
| `--key` | `key` | `certs/key.pem` |
| `--webui-dossier-dir` | `webui.dossierDir` | 空 |
| `--webui-projects-base-dir` | `webui.projectsBaseDir` | 空 |

未显式传入的参数不覆盖配置文件，其默认值只在配置文件也没有该键时生效。`-v`/`--version` 打印版本；子命令（`user`、`upgrade`）见 [安装服务端](/server#命令行参数)。

## 完整示例

列出全部键，取值为内置默认值；没有内置默认值的键标注为必填或示例值。安装包自带配置的差异见 [示例配置与内置默认值](#示例配置与内置默认值)。

```yaml title="server_config.yaml"
listen: 0.0.0.0
port: 443
cert: certs/cert.pem
key: certs/key.pem

logging:
  level: info                  # debug / info / warning / error
  format: text                 # text / json
  output: stderr               # stderr / stdout / none
  bufferSize: 5000

webui:
  enabled: true
  publicURL: ""                # 使用 Agentic IR 时必填
  userDBPath: data/users.db
  dossierDir: ""
  projectsBaseDir: ""

recon:
  responseTimeout: 300
  commandTimeout: 30

egress:
  rules:                       # 启用 WebUI 时必填，无内置默认值
    - purpose: siren_server_callback
      ipProtocol: TCP
      destCidrIp: 203.0.113.10/32
      portRange: 443/443
  discovery:
    uid: "1601097845544644"
    region: cn-hangzhou
    project: cloudfirewall-project-1601097845544644-cn-hangzhou
    logstore: cloudfirewall-logstore

mcp:
  enabled: true
  runOutputMode: auto          # auto / full
  cmdBlacklist: []             # 无内置默认值；安装包自带 30 条

air:
  provider: codex              # codex / claude / qoder / pi
  maxSessions: 20
  replayBufferBytes: 4194304
  prompt: 启动安全应急响应，UID：%s，Event ID：%s，SIREN Client ID：%d
  instancePrompt: 启动安全应急响应，UID：%s，ECS 实例 ID：%s，SIREN Client ID：%d，请先获取该实例的相关告警
  assetPrompt: 启动安全应急响应，UID：%s，云安全中心资产 UUID：%s，SIREN Client ID：%d，请先获取该资产的相关告警
  timeRangePrompt: "，告警时间范围：%s"
  customPromptPrefix: 在 SIREN Client %d 上启动安全应急响应。
  providers:
    codex:
      cliPath: codex
      args: [--no-alt-screen]
    claude:
      cliPath: claude
      args: []
    qoder:
      cliPath: qodercli
      args: []
    pi:
      cliPath: pi
      args: []
      agentDir: /root/.pi/agent
      contextModeDir: /root/.pi/context-mode
      memoryDir: /root/.pi/agent/memory
```

## 监听与证书

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `listen` | string | `0.0.0.0` | 共享 TLS 端口的监听地址，客户端、Web 控制台、WebSocket 和 MCP 共用，见 [单一 TLS 端口](/server#单一-tls-端口) |
| `port` | string / int | `443` | 共享 TLS 监听端口 |
| `cert` | string | `certs/cert.pem` | TLS 证书文件，须包含浏览器访问的域名和 `webui.publicURL` 的域名，见 [更换证书](/server#更换证书) |
| `key` | string | `certs/key.pem` | TLS 私钥文件 |

## logging

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `logging.level` | string | `info` | 最低日志级别：`debug`、`info`、`warning` 或 `error` |
| `logging.format` | string | `text` | `text` 或 `json`，见 [日志格式与留存](#日志格式与留存) |
| `logging.output` | string | `stderr` | `stderr`、`stdout` 或 `none`。`none` 只关闭终端输出，Logs 页面缓冲照常按 `logging.level` 保留记录 |
| `logging.bufferSize` | int | `5000` | Logs 页面在内存中保留的最近记录条数；`0` 或负数关闭 Logs 页面，见 [日志与审计](/logs#保留范围) |

`level`、`format`、`output` 不区分大小写，值无效时服务端拒绝启动。

### 日志格式与留存

`text` 每行一条记录：级别前缀、正文，结构化字段按字段名排序以 `key=value` 附在行尾。`json` 每行一个对象，固定包含 `time`（RFC 3339，含纳秒）、`level`、`message`，有字段时还有 `fields`：

```json
{"time":"2026-10-08T14:30:00.123456+08:00","level":"info","message":"client connected","fields":{"client_id":7,"component":"client","event":"client.connected","project":"global"}}
```

结构化记录带稳定的 `event` 字段，常见关联字段有 `request_id`、`client_id`、`session_id` 和 `duration_ms`，常用事件见 [日志与审计](/logs#常用审计事件)。

SIREN 不写日志文件也不轮转。Logs 页面缓冲只在内存中、重启即清空，不能代替持久化。需要留存时，重定向 `logging.output` 指向的输出流或用 tmux `pipe-pane` 采集，自行负责保留和轮转。服务端须运行在有终端输入的 tmux 中，见 [保持服务端运行](/server#保持服务端运行)。

## webui

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `webui.enabled` | bool | `true` | 是否提供 Web 控制台。关闭后 `/mcp` 仍按 `mcp.enabled` 提供；两者都关闭时只接受客户端连接 |

| `webui.dossierDir` | string | `""` | Dossier 静态文件目录，以 `/dossier/` 对外提供且不鉴权，见 [部署 Dossier](/server/dossier) |
| `webui.projectsBaseDir` | string | `""`（工作目录） | 新建 Project 目录的基准路径，不存在时自动创建；已有 Project 后不要更改，见 [基准目录](/projects#基准目录) |

## recon

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `recon.responseTimeout` | int（秒） | `300` | WebUI、REPL、MCP 等远程 Recon 等待客户端结果的上限；下发的采集预算为该值减 30 秒，见 [超时](/recon#超时) |
| `recon.commandTimeout` | int（秒） | `30` | MCP `run` / `run_batch` 和 REPL `run` 下发命令的超时，客户端再与自己的 `recon.commandTimeout` 取较小值 |

两个键为 `0` 或负数时使用默认值。客户端侧的 `recon.commandTimeout`、`recon.collectionTimeout` 和 Profile 见 [客户端配置](/reference/client-config#recon)。

## egress

### egress.rules

**Configure egress** 为目标 ECS 下发的出方向放行规则，部署也据此确定回连端口。没有内置默认值：启用 WebUI 时缺失或任一条无效，服务端拒绝启动；未启用 WebUI 时可以启动，但部署会失败。用途见 [出站规则 `egress.rules`](/server/prerequisites#出站规则-egressrules) 与 [出站放行](/onboard/egress#configure-egress)。

1 到 20 条规则，每条：

| 字段 | 要求 |
| --- | --- |
| `purpose` | 匹配 `^[a-z0-9_]{1,64}$`，不能重复。部署需要一条单端口 TCP 的 `siren_server_callback` 规则，`destCidrIp` 为客户端连接本服务端的公网 IP；缺少时部署失败，不影响启动 |
| `ipProtocol` | `TCP`、`UDP`、`ICMP`、`GRE` 或 `ALL`，不区分大小写 |
| `destCidrIp` | IPv4 CIDR，主机位必须为 0 |
| `portRange` | `TCP`、`UDP` 为 `起始/结束`，范围 1–65535 且起始不大于结束；`ICMP`、`GRE`、`ALL` 必须为 `-1/-1` |

`ipProtocol`、`destCidrIp`、`portRange` 三者相同的规则也不能重复。

### egress.discovery

部署未提供出口 IP 时，SIREN 通过 SOAR 查询云防火墙日志识别目标主机的出口 IP，见 [出口发现](/server/prerequisites#出口发现-egressdiscovery)。各字段可单独省略，省略时用默认值。

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `egress.discovery.uid` | string | `1601097845544644` | 云防火墙日志所在的阿里云账号 UID，加引号以免被解析为数字 |
| `egress.discovery.region` | string | `cn-hangzhou` | 日志服务地域 |
| `egress.discovery.project` | string | `cloudfirewall-project-1601097845544644-cn-hangzhou` | 日志服务 Project |
| `egress.discovery.logstore` | string | `cloudfirewall-logstore` | 日志服务 Logstore |

## mcp

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mcp.enabled` | bool | `true` | 是否在共享端口提供 `/mcp` 和 `/mcp/project/<id>`。为 `true` 时必须设置 [MCP 凭证环境变量](#环境变量)，否则拒绝启动。关闭后 Agentic IR 无法使用 |
| `mcp.runOutputMode` | string | `auto` | `run` 结果的默认返回方式：`auto` 对超过 8 KiB 的结果返回可回读的首尾预览；`full` 在 50 KiB 内返回完整结果，更大时仍返回预览。单次调用可用 `output_mode` 覆盖；值无效时记录警告并用 `auto`。见 [MCP](/reference/mcp) |
| `mcp.cmdBlacklist` | list（正则） | 无 | MCP `run` / `run_batch` 下发前检查的命令黑名单，无法编译的表达式记录警告后忽略。只作用于 MCP，见 [命令黑名单只作用于 MCP](/server/security#命令黑名单只作用于-mcp) |

<Callout title="删除 cmdBlacklist 等于不设黑名单" type="warn">
  `mcp.cmdBlacklist` 没有内置默认值。安装包自带的配置有 30 条拦截破坏性命令的规则；删除这个键或改用不含它的旧配置，MCP 将不拦截任何命令。
</Callout>

## air

各键的行为说明见 [准备 AIR Provider](/server/air-providers#配置项)。

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `air.provider` | string | `codex` | 浏览器所选 Provider 不可用时先回退到的 Provider：`codex`、`claude`、`qoder` 或 `pi` |
| `air.maxSessions` | int | `20` | GUI 与 Terminal 合计的并发会话上限，跨所有 Project；`0` 或负数表示不限制 |
| `air.replayBufferBytes` | int（字节） | `4194304` | 每个会话的断线重连回放预算；`0` 或负数时使用默认的 4 MiB，不会关闭回放 |
| `air.prompt` | string | `启动安全应急响应，UID：%s，Event ID：%s，SIREN Client ID：%d` | Event 入口按安全中心告警 ID 启动时的种子 prompt |
| `air.instancePrompt` | string | `启动安全应急响应，UID：%s，ECS 实例 ID：%s，SIREN Client ID：%d，请先获取该实例的相关告警` | Event 入口按 ECS 实例 ID 启动时的种子 prompt |
| `air.assetPrompt` | string | `启动安全应急响应，UID：%s，云安全中心资产 UUID：%s，SIREN Client ID：%d，请先获取该资产的相关告警` | Event 入口按云安全中心资产 UUID 启动时的种子 prompt |
| `air.timeRangePrompt` | string | `，告警时间范围：%s` | 实例或资产目标限定时间范围时追加在种子 prompt 后 |
| `air.customPromptPrefix` | string | `在 SIREN Client %d 上启动安全应急响应。` | Custom 入口加在用户 prompt 前的前缀，原样拼接，不去除首尾空白 |
| `air.providers.<name>.cliPath` | string | `codex`、`claude`、`qodercli`、`pi` | CLI 命令名或绝对路径；空字符串使该 Provider 不可用 |
| `air.providers.<name>.args` | list | `[]`；Codex 为 `[--no-alt-screen]` | 附加 CLI 参数，GUI 与 Terminal 共用，空字符串项被忽略；SIREN 接管的参数见 [Provider 参数](/server/air-providers#provider-参数) |
| `air.providers.pi.agentDir` | string | `/root/.pi/agent` | Pi 的全局配置、认证（`auth.json`）、Skills 与会话目录，见 [Pi](/server/air-providers#pi) |
| `air.providers.pi.contextModeDir` | string | `/root/.pi/context-mode` | Pi 长上下文卸载与恢复目录 |
| `air.providers.pi.memoryDir` | string | `/root/.pi/agent/memory` | Pi 跨会话长期记忆目录 |

`<name>` 为 `codex`、`claude`、`qoder` 或 `pi`。Prompt 模板占位符依次为 UID、目标 ID、Client ID（`timeRangePrompt` 只有时间范围，`customPromptPrefix` 只有 Client ID），修改时须保持数量和顺序，见 [Prompt 模板](/server/air-providers#prompt-模板)。

<Callout title="空字符串不会回退到默认值" type="warn">
  Prompt 模板和 `cliPath` 只在键不存在时使用内置默认值；空字符串是有效值，会生成残缺的 prompt 或让 Provider 不可用。要恢复默认，删除该键。
</Callout>

## 环境变量

凭证只从环境变量读取，不要写进 `server_config.yaml`、Project 目录或 Git 仓库。

### .env 加载

启动时依次加载工作目录和 `siren_server` 二进制所在目录下的 `.env`（同一文件只加载一次）。进程环境中已有的变量不被覆盖；两个文件定义同一变量时，工作目录的生效。文件不存在不报错；解析失败只记录一条带文件路径的警告，不输出文件内容。

其他设置方式（Shell 导出、REPL `env`）见 [设置服务端环境变量](/server/prerequisites#设置服务端环境变量)。

### 变量一览

| 变量 | 用途 | 何时读取 |
| --- | --- | --- |
| `SIREN_MCP_ADMIN_TOKEN` | 运维 MCP 客户端访问 `/mcp` 和任意 `/mcp/project/<id>` 的 Bearer 凭证 | 启动时。`mcp.enabled: true` 时必填 |
| `SOAR_ACCESS_KEY_ID` / `SOAR_ACCESS_KEY_SECRET` | SOAR 凭证，必须成对设置，用于 **Allow access**、**Configure egress**、**Restore egress**、**Deploy SIREN**、出口发现和 AccessKey 调查 | 首次调用 SOAR 时，之后缓存；见 [SOAR 凭证](/server/prerequisites#soar-凭证) |
| `ALIBABA_CLOUD_ACCESS_KEY_ID` / `ALIBABA_CLOUD_ACCESS_KEY_SECRET` | 两个 `SOAR_*` 变量都未设置时，经阿里云 SDK 默认凭证链使用 | 同上 |
| `SOAR_TRIGGER_QPS` | 触发 SOAR 剧本的速率上限，默认 `10`；持续出现 `Throttling.User` 时调低 | 首次调用 SOAR 时 |
| `SOAR_DESCRIBE_QPS` | 查询剧本执行结果的速率上限，默认 `20` | 首次调用 SOAR 时 |
| `SOAR_DESCRIBE_ATTEMPTS` | 查询剧本结果的默认最多尝试次数，默认 `20`，间隔 3 秒 | 首次调用 SOAR 时 |
| `CODEX_HOME` | AIR 从 `<CODEX_HOME>/sessions` 读取 Codex 历史会话，未设置时为 `~/.codex/sessions` | 每次列出历史时 |
| `LISTEN` / `PORT` / `CERT` / `KEY` | 覆盖同名顶层键，见 [优先级](#优先级) | 启动时 |

`SOAR_*` 速率与次数变量须为正整数，无效时记录警告并用默认值。REPL `env` 修改 SOAR 或阿里云凭证变量会立即重置 SOAR 客户端，其他变量须重启服务端才生效。

Agentic IR 启动 Provider CLI 时会剔除 MCP 凭证变量，其余环境变量原样传给 CLI，见 [MCP 鉴权](/server/security#mcp-鉴权)。

## 示例配置与内置默认值

安装包自带的 `server_config.yaml` 只在以下键上与内置默认值不同：

| 键 | 安装包示例 | 内置默认值 | 影响 |
| --- | --- | --- | --- |
| `egress.rules` | 三条规则，`siren_server_callback` 指向官方服务端 `47.111.170.208` | 无（必填） | 自建服务端部署前须改成自己的公网 IP 和端口；一键部署的客户端也连这个地址 |
| `mcp.cmdBlacklist` | 30 条破坏性命令规则 | 无 | 删除该键即不拦截任何命令 |
| `webui.dossierDir` | `/opt/siren/dossier` | `""` | 目录需单独部署，见 [部署 Dossier](/server/dossier) |
| `air.instancePrompt`、`air.assetPrompt`、`air.timeRangePrompt` | 以注释形式给出 | 见 [air](#air) | 取消注释后才覆盖默认值 |
| `webui.userDBPath`、`recon.commandTimeout` | 未出现 | 见对应表格 | 需要时手动添加 |
