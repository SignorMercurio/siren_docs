端口转发在服务端上打开一个 TCP 端口，把流量转发到目标客户端可访问的服务，常用于访问只在目标主机本机或内网开放的服务，例如仅监听 `localhost` 的 Web 管理后台或内网数据库。

<Callout title="仅 REPL 支持" type="info">
  端口转发只能通过 [服务端 REPL](/reference/repl) 的 `fwd` / `lsfwd` / `stopfwd` 命令操作，Web 控制台没有等价入口。
</Callout>

## 转发方向

```mermaid
graph LR
    A[操作者浏览器或客户端] -->|访问 服务端:8080| B[服务端<br/>监听源端口]
    B -->|SIREN 连接| C[SIREN Client<br/>目标主机]
    C -->|TCP 连接| D[目标服务<br/>localhost:8000]
```

<Callout title="监听范围" type="warn">
  转发端口开在服务端主机上并监听所有网络接口。服务端暴露在公网或共享网络时，用安全组、防火墙或仅本机访问限制来源，不要把敏感服务的转发端口暴露给不可信网络。
</Callout>

## 命令格式

`fwd` 的第二个参数有两种写法：

| 格式 | 目标地址 | 示例 |
| --- | --- | --- |
| `<serverPort>:<clientPort>` | 客户端侧 `localhost:<clientPort>` | `8080:8000` |
| `<serverPort>:<targetHost>:<targetPort>` | 客户端可访问的指定主机和端口 | `8080:192.168.1.10:3306` |

端口范围 `1–65535`，同一服务端源端口同时只能用于一条转发。

## 开始转发

例如通过服务端的 `8080` 端口访问目标主机的 `localhost:8000`：

```bash title="siren_server"
>>> fwd 0 8080:8000
```

浏览器与服务端在同一台机器时访问 `http://localhost:8080`，否则访问 `http://<服务端 IP>:8080`，并确认服务端网络策略允许该来源连接。

## 转发到客户端内网

连接从客户端一侧发起，`targetHost` 填从目标主机可达的地址，例如客户端所在内网的主机。客户端连不上该主机和端口时，转发也无法访问目标服务。

```bash title="siren_server"
>>> fwd 0 8080:192.168.1.10:3306
```

## 查看端口转发

```bash title="siren_server"
>>> lsfwd
```

输出列出 `Forward ID`、`Client ID` 和形如 `8080 -> localhost:8000` 的转发描述。

## 停止端口转发

```bash title="siren_server"
>>> stopfwd <Forward ID>
```

`Forward ID` 来自 `lsfwd` 输出，取值 `0–255`。停止后服务端关闭对应监听端口。客户端断线或服务端重启后，需要重新打开转发。

## 常见排查

- 源端口无法监听：端口是否被其他进程或已有转发占用，以及是否有权限监听。
- 访问源端口无响应：客户端是否在线，目标服务是否在监听，目标主机能否访问目标地址。
- 其他机器无法访问转发端口：服务端的防火墙、安全组或本机网络策略是否允许该来源。
