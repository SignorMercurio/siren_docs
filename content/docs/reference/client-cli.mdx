客户端二进制 `siren` 通常由 [一键部署](/onboard/provisioning) 或 [手动安装](/onboard/manual) 以连接模式拉起，下列子命令主要用于本地模式或排查。

## 全局参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-c`, `--config` | 依次查找工作目录和 `config/` 下的 `config.yaml` | 配置文件路径，键说明见 [客户端配置](/reference/client-config) |
| `-v`, `--version` | — | 打印版本 |

## 命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `client` | `siren client [-s <host>] [-p <port>]` | 连接服务端，进入常驻客户端模式 |
| `recon` | `siren recon [--profile <name>]` | 本地执行信息收集，结果上传 OSS |
| `info` | `siren info <pid> \| -p <port> \| -n <name>` | 查看进程详情（仅 Linux） |
| `upload` | `siren upload <file path>` | 将本地文件上传到 OSS |
| `clean` | `siren clean` | 清除 SIREN 管理的客户端文件并退出 |
| `probe-egress` | `siren probe-egress [--json]` | 观测一次出站 SYN，用于出口发现 |
| `upgrade` | `siren upgrade [-y]` | 检查并升级客户端二进制，`-y` 跳过确认 |
| `plugins` | `siren plugins [install\|uninstall\|toggle\|update <name>]` | 列出或管理本地插件 |

已安装的 command 类插件还会注册各自的顶层子命令，见 [插件](/reference/plugins)。

### client

`-s` / `-p` 省略时使用配置文件中的 `server` / `port`，默认 `127.0.0.1:443`。

```bash title="目标主机"
siren client -s 203.0.113.10 -p 443
```

### recon

省略 `--profile` 时使用配置中的 `recon.defaultProfile`。[快照](/reference/snapshot) 和报告都上传到 OSS。

### info

输出进程树、网络连接、容器与 systemd 信息等。`-p` 按监听端口、`-n` 按进程名查找，按名字命中多个进程时打印候选列表。

### clean

需要交互确认，见 [痕迹清除](/cleanup)。

### probe-egress

向配置中的 `server` / `port` 发出一次出站 SYN 并观测其五元组，供基于云防火墙的出口发现使用。`--json` 输出结构化证据。见 [出站放行](/onboard/egress)。

## 本地模式

目标主机无法回连服务端时，可作为次要方案在该主机上直接运行 `recon`、`info`、`upload`、`clean`，无需连接服务端。`recon` 和 `upload` 把结果写入 OSS，需在客户端配置 [OSS 凭证](/server/prerequisites#oss-凭证)，之后从 OSS 下载结果分析。
