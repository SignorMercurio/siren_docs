<Step>

### 准备凭证

本地模式 `./siren recon` 会把当前主机生成的报告上传至 OSS，因此需要先[设置 OSS 访问凭证](/credential#设置-oss-访问凭证)。远程模式和 WebUI Recon 不需要 OSS，报告会保存到 SIREN 服务端 Artifacts，并可通过 WebUI 查看。

</Step>
<Step>

### 开始自动化信息收集

```bash tab="本地模式"
./siren recon
```

```bash tab="远程模式"
>>> recon <Client ID>
```

```text tab="WebUI"
Web 控制台 -> Investigations -> Recon -> 选择客户端 -> Start Recon
```

信息收集过程中执行的每一条命令默认均有 30s 超时时间（可通过[配置文件](/config#客户端配置)调整）。本地模式完成后，会在当前主机同目录保存 Markdown 文件并上传 OSS；远程模式完成后，客户端会把 Markdown 报告回传给服务端，服务端将其保存为本地 artifact。

<Callout title="WebUI 进度" type="info">
  在 WebUI 中运行 Recon 时，页面会展示服务端从客户端日志中解析出的阶段列表，例如 `Recon.Basic`、`Recon.User`、`Recon.Process`、`Save report to Artifacts`。报告生成后可通过 Open Artifacts 直接打开服务端本地保存的 Markdown 文件。
</Callout>

<Callout title="Project 作用域" type="info">
  Recon 报告会保留客户端生成的原始 Markdown 文件名，通常形如 `SIREN_<host>_<timestamp>.md`。报告写入哪个目录取决于客户端的 Project 归属，见下方"查看数据"。
</Callout>

</Step>
<Step>

### 查看数据

本地模式输出的 Markdown 可使用任何 Markdown 阅读器/编辑器打开。远程模式和 WebUI 生成的报告会保存在服务端 Artifacts 中，可直接从 WebUI 的 Artifacts 页面打开、预览或下载。Global 视图查看服务端工作目录；Project 视图查看当前 Project 目录。

</Step>
</Steps>

## 信息收集模块

除基础信息外，下列模块均可通过[配置文件](/config#客户端配置)独立开关；基础信息每次运行都会采集，没有开关项。

<Accordions>
  <Accordion title="Linux 平台模块">

| 模块 | 配置项 | 采集内容 |
| --- | --- | --- |
| 基础信息 | 始终采集 | 当前时间、OS 发行版、主机名、当前用户、IP 地址、CPU 核数、CPU/内存/磁盘使用率、磁盘挂载（/etc/fstab） |
| 用户 | `recon.user` | 非默认用户、可登录用户、Root 权限用户、sudoers 用户、最近登录记录、`w`/`lastlog` 输出、登录 IP、新增用户记录、`/etc/passwd` 属性 |
| SSH | `recon.ssh` | SSH 暴力破解记录、`~/.ssh/config` 后门、`authorized_keys`、PAM/inetd/软链接后门、`sshd_config` 与 `sshd` 二进制属性 |
| 进程 | `recon.process` | CPU/内存占用 Top 20、systemd 启动进程、bash 反弹 shell、常见挖矿程序、其他非默认进程 |
| 网络 | `recon.network` | 监听端口、全 0 开放端口、已建立 TCP 连接、`/etc/hosts`、DNS 服务器、路由表、iptables 规则 |
| 计划任务 | `recon.cron` | 用户级与系统级 cron 任务、cron 可疑命令、cron 日志 |
| 服务 | `recon.service` | 运行中服务、非默认服务文件、`/etc/rc.local`、init.d/rc.d 启动项、启动项可疑命令 |
| 环境变量 | `recon.env` | 环境变量、`LD_PRELOAD`/`LD_LIBRARY_PATH` 等敏感变量、进程环境与 `/etc/ld.so.preload`、profile/rc/environment、`profile.d` 非默认脚本、alias |
| 文件 | `recon.file` | 历史命令及可疑命令、临时目录、SUID 文件、被进程锁定文件、近 1 天变更文件（mtime/ctime）、时间戳篡改、大文件（>200M）、coreutils 与系统软件包完整性、关键二进制属性 |
| Rootkit | `recon.rootkit` | 非默认内核模块、可疑内核模块（kallsyms）、可疑 `.ko` 模块 |
| Webshell | `recon.webshell` | Web 目录下 PHP/JSP 可疑文件扫描 |
| 应用 | `recon.application` | Redis 配置、JDWP 调试进程、Python 2/3 恶意软件包、容器列表 |

  </Accordion>
  <Accordion title="Windows 平台模块">

| 模块 | 配置项 | 采集内容 |
| --- | --- | --- |
| 基础信息 | 始终采集 | 当前时间、OS 版本、主机名、当前用户、IP 地址、CPU 核数、CPU/内存/磁盘使用率 |
| 用户 | `recon.user` | 非默认用户、可登录用户、管理员组成员、服务账户、禁用/隐藏账户、远程桌面用户、最近登录记录、当前登录用户、新增用户记录 |
| 进程 | `recon.process` | CPU/内存占用 Top 20、进程列表、PowerShell 反弹 shell、可疑进程、无文件进程 |
| 网络 | `recon.network` | 监听 TCP 端口、已建立 TCP 连接、hosts 文件、DNS 服务器、网络共享（SMB） |
| 计划任务 | `recon.schtask` | 计划任务、启动文件夹、系统启动项、注册表启动项（Run/RunOnce）、服务启动项 |
| 环境变量 | `recon.env` | 环境变量、PATH、PowerShell 配置文件、Windows Defender 排除项 |
| 文件 | `recon.file` | PowerShell 历史及可疑命令、临时目录、最近访问文件、近 30 天变更的系统目录可执行文件、近 1 天变更的系统日志、启动目录文件、卷影副本 |
| Webshell | `recon.webshell` | Web 目录下 PHP/JSP/ASP 可疑文件扫描、近 3 天 IIS 日志 |
| 应用 | `recon.application` | JDWP 调试进程、Python 2/3 恶意软件包、远程桌面配置、IIS 配置、Windows Defender 状态 |

  </Accordion>
</Accordions>
