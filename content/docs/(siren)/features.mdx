## 信息收集

<Cards>

    <Card title="用户" icon={<Users />} href="/recon">用户列表、登录历史、sudoers、新增用户记录等</Card>
    <Card title="SSH" icon={<Terminal />} href="/recon">SSH 配置、authorized_keys、暴力破解与后门检测等</Card>
    <Card title="进程" icon={<Activity />} href="/recon">进程列表、CPU/内存 Top 20、反弹 shell 与挖矿检测</Card>
    <Card title="网络" icon={<Network />} href="/recon">网络连接、监听端口、DNS 配置、路由表等</Card>
    <Card title="计划任务" icon={<Clock />} href="/recon">crontab、cron 日志、Windows 计划任务与启动项等</Card>
    <Card title="服务与启动项" icon={<Play />} href="/recon">systemd 服务、init 脚本、Windows 服务等</Card>
    <Card title="环境变量" icon={<Code />} href="/recon">系统环境变量、LD_PRELOAD 等敏感变量检查</Card>
    <Card title="文件" icon={<FileText />} href="/recon">近期修改文件、大文件、SUID 文件、文件完整性等</Card>
    <Card title="Rootkit" icon={<Cpu />} href="/recon">内核模块检查、可疑符号与 .ko 模块检测</Card>

    <Card title="应用" icon={<Package />} href="/recon">Redis/JDWP/恶意软件包检测、容器、IIS 等</Card>

## 报告与取证文件

SIREN 将本地报告、服务端 Artifacts 和 Dossier 报告编辑分成不同入口，用于查看采集结果、取证文件和应急报告。

<Cards>
    <Card title="本地 Recon 报告" icon={<FileText />} href="/recon#查看数据">本地模式生成结构化 Markdown 文件，可直接阅读，也可按客户端配置上传 OSS</Card>
    <Card title="服务端 Artifacts" icon={<FolderTree />} href="/webui#artifacts">集中查看远程 Recon 与 AIR 产出的结果文档，以及上传、整理和拉取到服务端的取证文件</Card>
    <Card title="Project 取证目录" icon={<FolderKanban />} href="/webui#projects">按应急响应项目固定服务端目录，Project 视图下 Artifacts、AIR 和 Recon 都落到对应目录</Card>
    <Card title="Dossier 报告编辑" icon={<BookOpen />} href="/dossier">面向 Markdown 应急报告编辑和附件保存，可直接打开默认报告或从 Artifacts 打开报告</Card>
</Cards>

## 文件与进程管理

对客户端文件系统、服务端 Artifacts 和进程信息进行查看、传输和分析。

<Cards>
    <Card title="客户端文件管理" icon={<FolderTree />} href="/webui#files">在线浏览客户端文件系统，支持预览、下载、目录打包和单文件上传</Card>
    <Card title="服务端 Artifacts 管理" icon={<Server />} href="/webui#artifacts">管理 Global 工作目录或 Project 目录中的报告、取证文件和上传文件，支持预览、下载、上传、新建目录、重命名和删除</Card>
    <Card title="本地文件上传" icon={<CloudUpload />} href="/analysis/upload">本地文件可上传至 OSS，远程 CLI 上传会拉取客户端文件并保存到服务端 Artifacts</Card>
    <Card title="进程分析" icon={<Activity />} href="/analysis/info">基于 PID/端口/名称查询进程详情、进程树、容器和服务信息</Card>
</Cards>

远程模式在本地模式的基础上，提供以下专属功能。

    <Card title="自动化客户端部署" icon={<Rocket />} href="/index#内部环境通过云助手一键部署">通过云助手单机或批量部署 SIREN 客户端到受害主机</Card>
    <Card title="自动重连与备注恢复" icon={<Radio />} href="/remote">客户端保存稳定身份，服务端重启后自动重连并恢复已设置备注</Card>

    <Card title="TLS 加密通信" icon={<Lock />} href="/protocol">所有客户端-服务端通信均通过 TLS 加密保护</Card>
    <Card title="端口转发" icon={<ArrowRightLeft />} href="/portforward">将受害主机内网服务转发到控制主机进行访问</Card>

    <Card title="痕迹清除" icon={<Eraser />} href="/misc/clean">远程清除受害主机上的 SIREN 痕迹</Card>

## Web 控制台

浏览器图形化入口，用于处理常用远程工作流；无需直接登录控制主机操作 tmux 或 REPL。

<Cards>
    <Card title="Web 控制台" icon={<LayoutDashboard />} href="/webui">统一入口访问客户端管理、Shell、Agentic IR、客户端文件与取证文件浏览等功能</Card>
    <Card title="Projects 工作区" icon={<FolderKanban />} href="/webui#projects">在 Global 与 Project 视图间切换，隔离客户端列表、操作目标和取证目录</Card>
    <Card title="账号鉴权" icon={<Lock />} href="/webui#账号鉴权">SQLite + bcrypt 账号登录，通过 CLI 管理用户</Card>
    <Card title="多标签 Shell" icon={<Terminal />} href="/webui#shells">WebSocket 承载的交互式终端，切换页面会话不中断</Card>
    <Card title="浏览器内 AIR" icon={<Brain />} href="/webui#agentic-ir">选择 Claude 或 Codex，查看 AI 回复、工具调用和结果，并继续追问</Card>
    <Card title="浏览器内调查" icon={<Key />} href="/webui#investigations">执行 AccessKey 调查、Recon 和进程分析，查看真实阶段进度并跳转报告</Card>
    <Card title="客户端文件浏览" icon={<FolderTree />} href="/webui#files">在线浏览客户端文件系统，支持预览、下载、目录打包和单文件上传</Card>
    <Card title="取证文件浏览" icon={<FolderTree />} href="/webui#artifacts">服务端 Artifacts 支持 Markdown 预览、Dossier 编辑、新建目录、上传、下载、重命名和删除</Card>
    <Card title="Dossier 报告编辑" icon={<BookOpen />} href="/dossier">从 WebUI 直接打开 Dossier 编辑器，编辑 Markdown 应急报告和附件</Card>
    <Card title="SOAR 快捷操作" icon={<MousePointerClick />} href="/webui#clients">allow、单机/批量 deploy、clean 一键调用，运行日志流式展示</Card>
</Cards>
