## 自动化信息收集

Recon 会在目标主机上采集客观状态。基础信息始终采集，其他模块由命名 Profile 组合；`default` 标准完整采集，`quick` 只跳过文件模块，显式 opt-in 的 `hunt` 面向应用拓扑、配置和凭据证据。Profile 不承载分析规则或结论，工具缺失、失败和截断会明确进入快照状态。

    <Card title="SSH 与登录" icon={<Terminal />} href="/recon">SSH 配置、authorized_keys、PAM 元数据、会话和登录记录</Card>

## 调查与响应

远程模式下，SIREN 可以把在线客户端、文件、进程、云上告警和 AI 会话集中到同一个调查现场。

<Cards>
    <Card title="浏览器 Shell" icon={<Terminal />} href="/webui#shells">在 Web 控制台打开多标签交互式终端，切换页面后会话保持运行</Card>
    <Card title="Agentic 应急响应" icon={<Brain />} href="/air">启动 Claude、Codex 或 Qoder 辅助排查会话，由操作员观察、追问和确认关键操作</Card>
    <Card title="AccessKey 调查" icon={<Key />} href="/ak">调用 SOAR 剧本查询泄露 AccessKey 的云上调用历史，生成 Markdown 报告</Card>
    <Card title="进程分析" icon={<Activity />} href="/analysis/info">按 PID、监听端口或进程名查询 Linux 进程详情、进程树、容器和服务线索</Card>
    <Card title="端口转发" icon={<ArrowRightLeft />} href="/portforward">把目标主机内网服务转发到控制主机，用于临时访问和验证</Card>
    <Card title="痕迹清除" icon={<Eraser />} href="/misc/clean">调查结束后清理客户端侧的 SIREN 文件和临时痕迹，并终止客户端进程</Card>
</Cards>

## 文件、Artifacts 与报告

SIREN 把客户端文件系统、服务端取证目录和报告编辑分成不同入口，避免把远端文件操作和报告整理混在一起。

    <Card title="客户端 Files" icon={<FolderTree />} href="/webui#files">浏览、预览、下载和上传在线客户端文件系统中的文件</Card>
    <Card title="服务端 Artifacts" icon={<FolderTree />} href="/webui#artifacts">管理 Global 工作目录或 Project 目录中的报告、取证文件和上传文件</Card>
    <Card title="文件管理" icon={<FileText />} href="/analysis/upload">了解 Web 控制台文件管理能力，以及本地模式和服务端 REPL 的 upload 命令</Card>

    <Card title="本地 Recon artifacts" icon={<FileText />} href="/recon#查看数据">本地模式生成权威 JSONL 与派生 Markdown，也可按配置上传到 OSS</Card>
