## v2.17.3 <DateTag>2026-08-04</DateTag>

### Bugfix

- 修复 GUI 图片粘贴能力判断：Claude 与 Codex 会明确启用图片输入，Qoder 则以当前 CLI 实际上报的能力为准；不支持图片的会话会在粘贴时直接提示
- 修复 GUI 消息发送被服务端校验或 Provider 拒绝时输入内容被清空的问题；文本和已粘贴图片现在会自动恢复到输入框

## v2.17.2 <DateTag>2026-08-04</DateTag>

### Feature

- GUI 输入框支持粘贴图片：每条消息最多 4 张、单张不超过 8 MiB（png / jpeg / webp / gif），粘贴后以可移除的缩略图暂存，随消息发送给 Agent，时间线中以图片数量徽标呈现。Claude、Codex、Qoder 均支持，Qoder 以其 CLI 上报的图片能力为准

## v2.17.1 <DateTag>2026-08-04</DateTag>

### Bugfix

- 修复 GUI 多轮导航刻度：悬停预览卡片此前被裁剪不可见；跟随底部时点击跳转会被自动滚动拽回原处。现在悬停会加宽刻度并显示预览，点击可平滑滚动到对应轮次

### Improvement

- GUI 输入框不再拦截未上报的斜杠命令：输入内容原样交给 Provider 处理，Provider 上报的命令仍有自动补全

## v2.17.0 <DateTag>2026-08-03</DateTag>

### Feature

- Agentic IR 默认使用结构化 GUI 时间线：Agent 回复原文与工具调用、命令、文件变更等操作记录按发生顺序交错，连续操作聚合为可展开的摘要行，计划以内联进度块呈现，审批和提问以卡片出现在对应位置
- 多轮会话左侧提供导航刻度，悬停预览各轮内容、点击跳转，向上翻阅后可一键回到最新；GUI 中可输入斜杠命令，Provider 上报的命令会自动补全
- Manual、Custom、Event 和 Resume 与 GUI / Terminal 分离；每次新会话默认 GUI，也可在启动前切换到保留真实 TUI、斜杠命令、自定义 statusline 和 PTY 重连的 Terminal
- 历史会话可先以只读时间线查看，只有点击 Continue session 后才恢复 Provider；停止后可在 GUI 与 Terminal 之间切换，服务端会阻止同一 Provider 会话被并发运行
- GUI 输入框下方新增 TUI 风格状态条，显示模型、上下文占用和订阅额度（含重置倒计时）：Codex 与 Claude 以 5h / 7d 窗口展示并支持手动刷新，Qoder Personal 显示模型与上下文并提供 Usage 入口

### Improvement

- GUI 不兼容时会在启动前明确禁用并回退到 Terminal，不会在运行中静默切换；GUI 与 Terminal 共用并发上限和有界断线回放容量

### Bugfix

- 多个部署目标共用出口 IP 时，已进入等待连接状态的目标会立即转为需要手工确认，不再等待超时后误报客户端未连接

## v2.13.0 <DateTag>2026-07-08</DateTag>

### Feature

- **新增 `recon` MCP 工具**：AIR / MCP 客户端可在指定客户端按需触发一次信息收集，等待回传并返回报告内容，报告同时保存到服务端 Artifacts；等待时间由新增配置 `mcp.reconTimeout`（默认 300 秒）控制
- **WebUI AIR 新增 Qoder Provider**：Agentic IR 页面可选择 QoderCLI 启动 Manual、Custom、Event 或 Resume 会话，并继续使用当前 Project 作用域的 SIREN MCP

### Improvement

- **Recon 收敛为快速、确定性的采集器**：移除挖矿程序、Webshell、Rootkit 符号、可疑命令、时间戳篡改等黑名单/签名判定（含独立的 Webshell 模块与 `recon.webshell` 开关），是否可疑改由 AIR 结合上下文判断，采集更快、噪声更低
- **Recon 文件模块提速**：将 SUID、近期变更（mtime/ctime）、大文件检查合并为一次全盘遍历（此前为四次），文件模块耗时约降至四分之一
- Codex AIR 注入的 SIREN MCP 工具默认允许执行，减少重复工具确认
- Qoder AIR 可列出并恢复当前工作目录下的 Qoder 历史会话；SIREN 只按会话注入自己的 MCP 配置，不修改用户的 Qoder 全局设置或权限策略

### Bugfix

- 修复 Project 视图下 AIR / MCP 可能错误看到或操作全局客户端的问题
