## v2.52.0 <DateTag>2026-11-25</DateTag>

### Breaking Change

- MCP `run` 只返回文本，不再有 `path`、`complete` 等结构化字段，外部客户端改读结果首行，见 [结果首行](/reference/mcp#结果首行)

### New Features

- AIR 新增常用请求：新建表单和 Chat 的 **Quick prompts** 菜单一键填入，内置项包括写成对客钉钉消息的「同步给客户」，列表在 Settings 的 **AIR** 标签中维护，见 [Settings](/webui#settings)
- 会话菜单新增 **Copy session ID**，复制 Provider 的会话 ID，见 [会话标题栏](/air/sessions#会话标题栏)
- 一个 Case Board 有多份报告时，每份报告只和自己覆盖的排查项比对是否过期，见 [Case Board](/air/case-board)
- Dossier 新增版本历史、交付检查、简报、日志证据块和截图占位；别处改写正在编辑的报告时，自动载入或提示合并。这些功能需要重新发布 Dossier 运行时，见 [报告](/reports) 和 [部署 Dossier](/server/dossier)

### Improvement

- AIR Chat 队列暂停时显示 **Resume queue**，回到 Chat 时用 **New since you left** 标出新内容，见 [排队消息](/air/gui#排队消息)
- AIR 会话空闲自动停止的默认时长改为 48 小时，已有服务端需手动修改 `air.idleTimeoutHours`，见 [服务端配置](/reference/server-config#air)
- Pi 的 Kimi 模型换成 Kimi K3.1 Pro Prime，重新运行 Pi 安装脚本后生效，Usage 单价需从安装包模板复制，见 [准备 AIR Provider](/server/air-providers#pi)
- MCP `recon` 和 `case_read` 的结果过长时只返回概要，全文写入文件，见 [MCP 参考](/reference/mcp)
- MCP `case_update` 被拒时一次列出全部错误，`host` 实体也接受实例 ID、内网 IP 和主机名，见 [`case_update`](/reference/mcp#case_update)
- MCP `run` 超时时，结果第二行给出处理办法，见 [结果首行](/reference/mcp#结果首行)
- Dossier 中超过一页高的图片缩到一页内，加载失败的图片显示路径

### Bug Fixes

- Claude Code 会话不再在约 60 秒时放弃等待耗时较长的 SIREN 工具调用
- Dossier 响应阶段之后的 `####` 小节不再与第一个阶段重号

## v2.51.0 <DateTag>2026-11-23</DateTag>

### Breaking Change

- Recon 快照格式变化，服务端和客户端必须一起升级，见 [版本一致](/upgrade#版本一致)

### New Features

- AIR Chat 支持排队消息：运行中按 Cmd+Enter（Windows 和 Linux 上为 Ctrl+Enter）把消息排到下一轮，见 [排队消息](/air/gui#排队消息)
- AIR Chat 把结束的轮次折叠为最后的回复；输入框为空时按 ↑ 取回发过的请求，选中文字后点击 **Quote** 引用，见 [AIR GUI](/air/gui)
- Agentic IR 左栏显示会话的 **Working**、**Completed** 或 **Failed** 状态，并按第一条消息自动生成中文标题，见 [左栏](/air/sessions#左栏)
- 新建 Chat 会话默认打开 **Delegate to workers**，见 [多 Agent 分工](/air/sessions#多-agent-分工)
- Clean 成功后自动恢复实例的出站规则，**Restore egress** 的记录按 UID 分组，见 [恢复出站规则](/restore-egress)
- Case Board 只对照最新一份报告，各维度默认显示最新 3 条发现，见 [Case Board](/air/case-board)
- Artifacts 的文件预览显示大小、修改时间和 SHA-256，见 [浏览与预览](/artifacts#浏览与预览)
- Pi 新增百炼上的 Qwen4 Max 模型

### Improvement

- WebUI 改用暖色深色配色和单一紫色强调色
- 从 Global 视图启动 AIR 时自动切到客户端所属的 Project，Project 的 Clients 页可以加入未分配的客户端
- Clients 页滚动时工具栏和表头保持固定，实例 ID 或主机名列改名为 **Host**，见 [表格列](/clients#表格列)
- Usage 价格表新增 GPT-6.2 Astra、Claude Fable 5.2 等模型，已有服务端需从安装包模板复制，见 [费用估算](/usage#费用估算)
- `case_update` 关闭排查项时自动清空残留的 `next_action`，不再拒绝整次更新
- **Customer order UID** 改名为 **Customer UID**

### Bug Fixes

- 从 History 继续的 Chat 会话显示之前的轮次
- macOS 服务端上 Pi 的 Terminal 会话不再启动超时
- 手机上 Agentic IR 左栏自动收起，Usage 和 Files 的控件不再被截断

## v2.50.0 <DateTag>2026-11-13</DateTag>

### Breaking Change

- MCP 移除 `read_run_result` 和 `search_run_result`，`run` 的输出保存到 Project 目录的 `runs/<audit_id>.txt`，Agent 用文件工具读取，见 [结果文件](/reference/mcp#结果文件)
- 移除 `mcp.runOutputMode`；MCP 命令时限最多 120 秒，不再参考客户端的 `recon.commandTimeout`，见 [执行时限](/reference/mcp#执行时限)
- 客户端日志改为分帧发送，服务端和客户端必须一起升级，见 [版本一致](/upgrade#版本一致)

### New Features

- 范围菜单新增 **Search projects**，按名称、负责人或 UID 搜索 Project，桌面浏览器中按 `⌘K`（Windows 和 Linux 上为 `Ctrl+K`）打开，见 [范围菜单](/webui#范围菜单)
- MCP `run` 和 `run_batch` 新增 `timeout_seconds`，见 [执行时限](/reference/mcp#执行时限)
- Claude Code GUI 会话的一次提问可以包含多个问题，见 [审批与提问](/air/gui#审批与提问)

### Improvement

- 命令黑名单新增 Windows 破坏性命令规则，已有服务端需从安装包模板复制，见 [命令黑名单](/reference/mcp#命令黑名单)
- Codex 和 Pi 等待一次 SIREN 工具调用最长 330 秒，同一客户端上排队的命令最多等待 130 秒，见 [同一客户端的并发](/reference/mcp#同一客户端的并发)
- 一键部署遇到云助手离线时，提示客户恢复云助手后重新部署，见 [一键部署](/onboard/provisioning#结果与记录)
- 中文界面翻译 AIR 会话的结束原因，日期和数字按界面语言格式显示

### Bug Fixes

- 中文界面的分段按钮和表头文字不再换行
- 切换 Project 后，Files 页不再请求上一个 Project 的客户端

## v2.49.0 <DateTag>2026-11-11</DateTag>

### New Features

- WebUI 新增简体中文界面，默认跟随浏览器语言，可以在 Settings 的 **Language** 中切换，见 [界面语言](/webui#界面语言)

### Improvement

## v2.48.0 <DateTag>2026-11-10</DateTag>

### Breaking Change

- 多 Agent 分工改为按会话开启：启动表单新增 **Delegate to workers** 开关，Settings 中的全局开关移除，见 [多 Agent 分工](/air/sessions#多-agent-分工)
- 服务端和客户端不再从 `PORT`、`SERVER` 等环境变量读取配置，见 [服务端配置](/reference/server-config#优先级)
- `egress.discovery` 不再有内置默认值，缺字段时不做出口发现，见 [出口发现](/server/prerequisites#出口发现-egressdiscovery)
- `mcp.cmdBlacklist` 中有无法编译的正则时，`run` 和 `run_batch` 拦截全部命令，见 [命令黑名单](/reference/mcp#命令黑名单)

### New Features

- 可以单独停止运行中的 worker，见 [多 Agent 分工](/air/sessions#多-agent-分工)
- MCP 新增 `allow` 和 `egress`，AIR 可以在你明确要求时放行客户端 IP、配置出站规则，见 [`allow`](/reference/mcp#allow)
- Case Board 的文件、账号和资源实体可以带所在主机，见 [`case_update`](/reference/mcp#case_update)

### Improvement

- worker 把实体和攻击事件写回 Case Board，请求审批或提问时由 SIREN 自动答复
- **Restore egress** 默认只显示还需要处理的记录
- Linux 和 macOS 的 `hunt` Profile 重新包含 `rootkit` 模块
- Recon 读取轮转和压缩的 `secure`、`auth` 日志，并遮盖客户端自身的 OSS 凭证

### Bug Fixes

- 客户端连接读取出错后结束会话，不再反复报错
- 插件命令的参数不再被二次拆分
- 修改客户端备注时检查客户端所属的 Project
- MCP 审计日志不再包含命令输出

## v1.3.0 <DateTag>2025-05-15</DateTag>

- 服务端新增 `!` 执行本地命令，新增 `env` 设置环境变量
