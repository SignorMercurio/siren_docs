GUI 是 AIR 会话的默认界面：SIREN 把 Provider 的事件按轮次整理成调查时间线，操作员在同一处查看回复和操作、回答审批与提问、补充指令。各 Provider 的差异见 [Provider 差异](/air/providers)。

## 时间线结构

每一轮（turn）从操作员的请求开始，按发生顺序交错展示 Agent 的 Markdown 回复、操作记录（命令、文件、搜索、MCP 工具等）、**Plan** 进度、审批与提问卡片和 Provider 通知；特定工具的结果下方追加 [结构化结果卡](#结构化结果卡)。连续操作聚合为一行摘要，点击展开可查看完整命令、输入和输出；失败的操作标记 `failed`。点击操作中的文件路径，在该会话所属 Project 的 Artifacts 中打开。

## 发送请求与调整方向

在底部输入框按 Enter 发送，Shift+Enter 换行。

- **空闲时**：开启新的一轮。
- **运行中**：内容作为方向调整交给当前轮次，带 **Steered** 标签。各 Provider 的处理方式见 [Provider 差异](/air/providers#运行中调整方向)。
- **停止当前轮次**：点击输入框右侧的停止按钮，只停止这一轮，会话保持连接。Codex、Claude 和 Qoder 中等待处理的审批与提问随之取消，记录为 `Cancelled`。结束整个会话见 [启动与管理会话](/air/sessions#停止与结束)。

<Callout title="调整方向不会撤销已完成的操作" type="warn">
  方向调整和停止只影响 Agent 之后的行为。已执行的命令、文件修改和对客户端的远程操作不会回滚，请在时间线中核对。
</Callout>

## 审批与提问

Provider 需要操作员决定时，Agent 暂停并在时间线中插入卡片，输入框上方出现提示条（**Approval required** 或 **Agent question**），点击 **Show request** 跳到对应卡片。

**审批卡**（Approval required）显示请求摘要，以及 Provider 提供的路径、命令、写入内容和其他参数。写入内容超过 20 行时只显示前 20 行，复制按钮可得到全文。底部按钮是 Provider 提供的选项，例如 **Allow once**、**Allow for session**、**Decline**，差异见 [Provider 差异](/air/providers#审批)。

**提问卡**显示问题和选项，点击选项即作答，或点击 **Answer in your own words** 自由回答。

处理后，卡片收起为一行决策记录（`Allowed once`、`Allowed for session`、`Declined`、`Cancelled`、`Expired` 或 `Answered`），刷新或在其他浏览器接入后仍可见。

## 检索与过滤

按 Cmd/Ctrl+F 打开检索条，只读历史同样可用。除关键词外，可用过滤 chip 只保留 **Failed**（失败的操作）、**Commands**（命令）、**Files**（文件修改）或 **Requests**（审批与提问），多个 chip 取并集。

## 状态条

输入框下方的状态条显示：

| 项 | 说明 |
| --- | --- |
| **Model** | 当前模型和推理强度。支持切换的 Provider 空闲时可点击切换，见 [Provider 差异](/air/providers#模型与推理强度) |
| **Ctx** | 上下文占用百分比，Provider 未报告上限时不显示 |
| 额度窗口 | 如 `5h 80% (2h13m)`：窗口、剩余百分比和重置倒计时。Provider 不提供可编程额度时显示原因或 **Usage** 外链，不做估算 |
| **Stale** | 额度数据被 Provider 标记为过期，或超过 10 分钟未更新 |

状态条右侧还有检索、导出 Markdown 和刷新额度按钮。各 Provider 能显示哪些项见 [Provider 差异](/air/providers#额度与上下文)。

## 斜杠命令

在输入框键入 `/` 打开命令菜单。运行中，只能在空闲时执行的命令标记 `idle only`。

所有 Provider 都提供 `/status`：显示连接、Provider、模型、SIREN 和 Provider 会话 ID、当前轮次、Project、上下文占用及额度。它随时可用，不发送给 Provider，也不写入 Provider 历史。其他命令见 [Provider 差异](/air/providers#gui-命令)。

## 粘贴图片

在输入框中直接粘贴截图，随下一条消息发送，数量和大小限制见 [限制](/reference/limits#air)。当前会话不接受图片时提示 "This provider session does not accept pasted images"，各 Provider 的支持见 [Provider 差异](/air/providers#图片输入)。

## 结构化结果卡

部分工具成功返回后，操作行下方追加结果卡：

| 结果卡 | 来源 | 内容与操作 |
| --- | --- | --- |
| **Collected evidence** | SIREN MCP `recon` | Recon Profile、状态（`complete` 或 `partial`），以及报告和快照路径，点击在 Artifacts 中打开 |
| **Command outcomes** | SIREN MCP `run_batch` | 每台主机的 Host、Outcome、Exit |
| **Security Center alerts** | 阿里云安全中心告警查询结果 | 告警名称、等级、Event ID、主机和时间。带进程 ID 的告警显示 **Inspect PID N**，跳到 [Investigations](/webui#investigations) 的进程分析；要求该会话所属工作区中恰好有一台匹配的在线 Linux 客户端 |
| **Report** | Agent 交付的 Markdown 报告 | 见下文 |

告警卡只展示数据源返回的等级和字段，不代表 SIREN 判定主机已失陷。

### Report 卡

一轮结束时，如果 Agent 在该轮成功写入或修改了 `.md` 文件，或在回复中用 Markdown 链接明确指向某个 `.md` 文件，且该文件存在于会话工作区中，该轮末尾出现 **Report** 卡：

- **Preview**：在 Artifacts 中打开报告。
- **Edit in Dossier**：在新标签页用 Dossier 继续编辑。Dossier 未部署或不可用时按钮置灰并显示原因，见 [部署 Dossier](/server/dossier)。

报告位置和证据链接的解析规则见 [证据与报告](/air/evidence)。

## 导出 Markdown

点击状态条中的导出按钮，把当前时间线下载为 Markdown 文件，运行中的会话和只读历史都可导出。文件包含会话信息和每轮的请求、回复、操作记录（命令原文和输出）、计划、审批与提问及决策记录。单个输出超过 200 行时只保留前 200 行。脚注处理见 [证据与报告](/air/evidence#导出会话)。

<Callout title="导出内容以已加载的时间线为准" type="info">
  只读历史初次打开时只加载最近 200 条事件，更早的内容需点击顶部的 **Load earlier activity** 加载后才会导出。运行中会话重新接入后，超出回放缓存的早期内容同样不会导出，见 [重新接入与回放](/air/sessions#重新接入与回放)。
</Callout>
