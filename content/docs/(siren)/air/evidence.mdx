在 AIR 的 GUI 会话中，SIREN 要求 Agent 为调查结论标注证据来源，并把临时取得的原始输出保存到工作区。

<Callout title="只适用于 GUI 会话" type="info">
  证据要求随 GUI 会话注入，四个 Provider 均适用。[Terminal 界面](/air/terminal) 不注入这些要求，回复中通常没有可点击的来源卡片。
</Callout>

## SIREN 对 Agent 的要求

启动或继续 GUI 会话时，SIREN 在 Provider 的系统提示后附加一段证据说明，操作者已有的追加提示保留。要点：

- **用脚注引用**：实质性结论用 Markdown 脚注（`[^1]`）标注来源，普通提问和进度更新不需要。
- **脚注内容**：证据摘要、实际数据来源（主机和原始路径，或云账号、日志库、告警或记录 ID）、带时区的采集时间和查看原件的位置；日志查询另写查询时间范围。
- **复用已有材料**：优先引用工作区中已有的 Recon 报告、JSONL 快照等文件。
- **保存临时输出**：依赖临时命令或云端查询的输出前，在权限允许时把原始输出或标注清楚的摘录保存到工作区的 `evidence/` 目录（不覆盖已有文件），并记录来源、采集时间、完整命令或查询语句，以及截断或缺失情况。
- **不得编造**：只引用实际取得的材料，保存、定位或读取失败时在脚注中说明缺口并省略链接。AI 生成的摘要不算原始证据。

这段说明不授予额外权限：Agent 写入 `evidence/` 时仍按 [审批](/air/providers#审批) 规则请求确认。

## 在时间线中查看来源

带脚注的回复中，点击编号 `[1]`、`[2]` 打开来源卡片，显示该脚注的全部内容；每条回复下方的 **Sources (N)** 可展开该回复的全部来源。来源卡片的内容由 Agent 撰写，SIREN 不验证其真实性。

## 链接如何打开

回复、操作行和结果卡中的链接：

- 工作区内的相对路径（如 `evidence/20261008-1430-ps-a1b2.txt`）在该会话所属 Project 的 Artifacts 中打开，即使当前在其他 Project 视图。
- `http://` 或 `https://` 地址在新标签页打开。
- 含 `..`、以 `.` 开头的目录或文件、工作区之外的绝对路径和其他协议不可点击。

在 [Artifacts](/artifacts) 中预览 Markdown 报告时，相对链接按报告所在目录解析，可以用 `..` 指向上级目录但不能超出工作区。以 `/` 开头的路径和以 `.` 开头的目录或文件不可点击。

## 报告存放位置

报告和 `evidence/` 目录位于 Provider 的工作目录，由启动会话时的视图决定：

| 视图 | 工作目录 | 在 WebUI 中查看 |
| --- | --- | --- |
| Project | 该 Project 的目录 | 该 Project 的 Artifacts |
| Global | `siren_server` 进程的当前工作目录 | Global 视图的 Artifacts |

Agent 写入或明确链接 `.md` 报告后，该轮末尾出现 **Report** 卡，见 [GUI 时间线](/air/gui#report-卡)。在 Dossier 中编辑和导出报告见 [Dossier 工作流](/reports)，成品示例见 [示例报告](/air/example)。

## 导出会话

[导出](/air/gui#导出-markdown) 的 Markdown 文件保留回复中的脚注，不同回复的脚注编号自动加前缀以免冲突。

## 核验结论

脚注只说明 Agent 声称的来源，不等于证据已经核实。把结论写进报告前，逐项检查：

1. **每条关键结论都有脚注**。没有脚注的结论视为未经核实，可以追问 Agent 取证补充。
2. **打开原件**。点击来源卡片中的链接，在 Artifacts 中查看 `evidence/` 文件或 Recon 报告，确认摘录与结论一致。
3. **核对采集信息**：命令或查询语句、主机、采集时间和时区、日志时间范围，以及是否注明截断或缺失。
4. **留意声明的缺口**。注明 “保存失败”“无法定位” 的来源只能作为线索。
5. **独立复核关键事实**。必要时在 [Shells](/shells) 或 [Investigations](/webui#investigations) 中自行执行命令或查看进程。安全中心告警卡展示的是数据源返回的等级，不是失陷判定。
6. **核对操作记录**。用 **Failed**、**Commands**、**Files** 过滤时间线，确认 Agent 实际执行过的操作，以及是否有失败被忽略。
