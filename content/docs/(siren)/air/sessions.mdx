**Agentic IR** 页面左栏从上到下是启动表单、**Running** 列表和 **History**，右侧以标签页显示已打开的会话。Provider 的服务端准备见 [准备 AIR Provider](/server/air-providers)。

## 选择 Provider 和界面

启动表单第一行是 Provider 按钮（Codex、Claude、Pi、Qoder）和一个终端图标按钮：

- **Provider 按钮**：服务端不可用的 Provider 置灰，原因见 [检查可用性](/server/air-providers#检查可用性)。
- **终端图标**：未按下用 **GUI**，按下用 **Terminal**。某种界面不可用时页面自动改用另一种。

页面在当前浏览器记住上次选择的 Provider 和界面。要固定默认值，在 **Settings** 的 **Default AIR provider** 和 **Default AIR surface** 中选择。所选 Provider 不可用时回退到服务端配置的 `air.provider`。

## 入口模式

Provider 下方有三个入口模式，默认选中 **Custom**：

| 模式 | 需要填写 | 会话开始时 |
| --- | --- | --- |
| **Manual** | 无 | 空白会话，不绑定客户端，没有开场提示词 |
| **Custom** | **Client**、**Prompt** | 把 Client ID 前缀和你的描述作为开场提示词 |
| **Event** | **Client**、**UID**、**Target** | 把账号 UID、事件目标和 Client ID 作为开场提示词，让 Agent 先查相关告警。SIREN 不代为查询，能否查到取决于 Provider 自身的工具或 Skill |

三种模式都注入当前范围的 SIREN MCP。开场提示词模板由运维人员配置，见 [Prompt 模板](/server/air-providers#prompt-模板)。在 [Clients 页](/clients) 点击某一行的 AIR 图标，会以 **Custom** 模式选中该客户端。

### Event 目标

**Target** 下拉框选择目标类型，再填入对应 ID：

| 目标 | 填写 |
| --- | --- |
| **Event** | 一条安全中心告警的 ID |
| **ECS** | ECS 实例 ID（`i-…`），查该实例的相关告警 |
| **Asset** | 云安全中心资产 UUID，查该资产的相关告警 |

选择 **ECS** 或 **Asset** 时，可以展开 **Time range** 限定告警时间：**Default**（由 Agent 决定）、**3d**、**7d**、**30d** 或 **Custom**（必须填 **From**）。时间按字面值写入提示词，不做时区换算。

<Callout title="告警 ID" type="info">
  **Event** 目标的 ID 指阿里云安全中心告警详情页“基础信息”中的“告警 ID”，不是“关联安全事件”里的“事件 ID”。
</Callout>

## Project 范围

会话启动时的范围决定它的工作目录和 MCP 范围，之后不随侧栏切换而改变：

| | Global | Project 视图 |
| --- | --- | --- |
| 工作目录 | 服务端进程的工作目录 | 该 Project 的 Artifacts 目录 |
| SIREN MCP 与 **Client** 下拉框 | 全部客户端 | 本 Project 的客户端 |
| **Running** 和 **History** | 服务端上的全部会话 | 本 Project 的会话 |

切换范围时，属于其他范围的会话标签会被关闭，但会话继续运行，回到原范围后可从 **Running** 重新打开。完整规则见 [Project 范围](/projects)。

## 会话标签

每个会话在右侧的一个标签中打开。关闭标签只关闭视图，不停止会话；刷新浏览器后已打开的标签自动恢复。地址栏中的会话地址可以直接分享或收藏。

## Running

**Running** 列出当前范围内运行中的会话，每行显示标题、启动时间、客户端和入口模式，等待操作员时显示 **Approval required** 或 **Question waiting**。点击一行即接入该会话。列表刷新失败时显示 `List may be stale: ...`，其中可能包含已不存在的会话。

### 待处理提示

GUI 会话等待审批或回答时，对应会话标签上也会出现标记；浏览器停留在 Agentic IR 页面时，标签页标题加上 `● Approval` 或 `● Question` 前缀，即使等待的不是当前显示的会话。Terminal 会话的审批出现在 TUI 内，不触发这些提示。

## 重新接入与回放

会话托管在服务端，刷新浏览器、切换页面、关闭会话标签或短暂断网都不会中断它。重新打开时，页面先回放服务端缓存的内容，再继续显示实时输出；多个浏览器可以同时查看同一会话。

连接中断后页面自动重连，仍未恢复时显示以下提示和 **Reconnect** 按钮：

- GUI：`Stream disconnected · the session may still be running on the server.`
- Terminal：`Connection lost · the session may still be running on the server.`

回放缓存有容量上限（`air.replayBufferBytes`，默认 4 MiB）。更早的内容已被挤出缓存时，GUI 时间线顶部显示 `Earlier activity is no longer in the replay buffer (N events dropped).`，点击 **Open full transcript** 只读打开 Provider 保存的完整记录；Terminal 见 [重新连接](/air/terminal#重新连接)。

## 停止与结束

点击 **Running** 行右侧的关闭按钮，在 **Stop session** 对话框中确认即可结束会话。Provider 进程被终止，会话记录保留在磁盘上，之后可从 **History** 继续。只停止 GUI 当前这一轮见 [GUI 时间线](/air/gui#发送请求与调整方向)。

会话结束后，已打开的标签保留内容，顶部显示 **Session ended** 和原因：

| 原因 | 含义 |
| --- | --- |
| `session stopped by an operator` | 有人在 Running 中停止了会话 |
| `session ended: the agent process exited` | Provider 进程自行退出 |
| `session ended: server shut down` | SIREN 服务端正在关闭 |
| `unknown agent session` | 服务端上已没有该会话，通常因为服务端重启过 |

会话未能启动时，GUI 显示 **Session did not start**、原因和 **Retry** 按钮，Terminal 显示 **Session ended** 和错误原因。常见原因：

| 报错 | 处理 |
| --- | --- |
| `agent session limit reached (N)` | 全服务端同时运行的会话数（GUI、Terminal 和所有 Project 合计）已达上限。先在 Running 中停止不用的会话；上限见 [配置项](/server/air-providers#配置项) 中的 `air.maxSessions` |
| `session <ID> is still running; stop it before resuming` | 要继续的历史会话仍在运行，见 [同一会话不能同时运行两份](/air/terminal#同一会话不能同时运行两份) |
| `webui.publicURL is required for AIR MCP` 或 CLI 自身的登录错误 | 服务端准备不完整，见 [准备 AIR Provider](/server/air-providers#常见问题) |

### 服务端重启

SIREN 服务端正常关闭时结束所有运行中的会话，让 Provider 保存会话记录；服务恢复后，已保存的会话可从 **History** 继续。强制结束进程、主机断电，或 Provider 还没创建会话记录时，不保证历史一定存在。

## History

**History** 收起在左栏底部，点击展开。

- **范围**：只列出当前选中 Provider、当前范围工作目录下的会话。要看另一个 Provider 的历史，先切换 Provider 按钮。
- **内容**：按更新时间倒序，最多 50 条；运行中的会话和没有用户输入的会话不列出。
- **搜索**：按空格拆分关键词，要求全部命中，匹配会话 ID、时间、输入、消息和分支。

### 继续历史会话

1. 点击 History 中的一行，会话以只读时间线打开。
2. 点击 **Continue session** 用 GUI 继续，或在该 Provider 的 Terminal 可用时点击 **Continue in Terminal**。

会话以原 ID 在新标签中重新启动，工作目录和 MCP 范围取当前范围。
