Clients 页（`#/clients`）是 WebUI 的默认首页，列出当前范围内的在线客户端，Shell、AIR、文件、Recon、进程分析和清理都从客户端行发起。还没有客户端时，见 [选择接入方式](/onboard)。

![Clients 页的客户端表格，含 Project 分配、Note 和行内操作按钮](../../img/clients-table.png)

## 表格列

| 列 | 内容 |
| --- | --- |
| **ID** | Client ID，重连和服务端重启后不变，见 [核心概念](/concepts#siren-server-与-client) |
| **Instance ID** | 阿里云 ECS 实例 ID；未上报时显示主机名 |
| **Private IP** | 第一个内网 IP，有多个时附 `+N` |
| **Project** | 所属 Project，未归属显示 **Unassigned**；仅 Global 范围下可编辑 |
| **Note** | 客户端备注，点击编辑 |

悬停 **Instance ID** 单元格会弹出主机卡片，显示 **Hostname**、**Version**、**Address**（客户端连接地址）和全部 **Private IP**。

## 筛选与刷新

筛选框不区分大小写，按子串匹配 Client ID、OS、连接地址、Note、Project 名、主机名、Instance ID 和全部内网 IP。

列表按 **Settings** → **Client list refresh** 轮询（默认 10 秒，只存于当前浏览器）。连续 3 次失败时表格上方显示 `Unable to reach server`。

## 编辑 Note

点击 **Note** 单元格输入备注（最多 256 个字符），按 Enter 或失焦保存，Esc 放弃；清空后保存即删除。保存失败提示 "Couldn't save note. Press Enter to retry."。

Note 按客户端稳定身份保存，重连或服务端重启后仍在。客户端选择器、Shell 和 AIR 标签名、MCP `ls` 输出（AIR 也能看到）都会显示它。

## 行内操作

| 入口 | 结果 |
| --- | --- |
| Shell 图标 | 新开浏览器 Shell 标签并跳到 [Shells](/shells) |
| AIR 图标 | 跳到 [Agentic IR](/air)，切到 **Custom** 模式并选中该客户端 |
| **More actions** → **Files** | 跳到 [Files](/files) 并选中该客户端 |
| **More actions** → **Recon** | 跳到 Recon 标签并选中该客户端；选 Profile 后点 **Start Recon** 才执行，见 [Recon](/recon) |
| **More actions** → **Process analysis** | 跳到 [进程分析](/process)，仅 Linux 客户端可用 |
| **More actions** → **Clean & terminate** | 输入该客户端 ID 确认后点 **Send cleanup request** |

**Clean & terminate** 让客户端删除 SIREN 管理的文件并退出，服务端无法确认最终删除结果，见 [痕迹清除](/cleanup)。

## 批量操作

勾选客户端后，工具栏变为批量操作栏：

- **Assign project**：仅 Global 范围显示，选 Project 或 **Unassigned** 后立即生效，不再确认。规则见 [Project 范围](/projects)。
- **Clean N**：输入选中数量后点 **Send N requests**。

批量操作作用于全部已选客户端，包括被筛选隐藏的（计数旁显示 `· M hidden by filter`），执行前先确认。

## Provisioning

表格下方的 **Provisioning** 面板通过 SOAR 操作阿里云 ECS：**Deploy SIREN** 见 [一键部署](/onboard/provisioning)，**Allow access** 和 **Configure egress** 见 [出站与入站放行](/onboard/egress)，**Restore egress** 见 [恢复出站规则](/restore-egress)。

## Recent activity

**Recent activity** 合并显示近期部署（Deploy）和清理（Cleanup）记录，Project 视图只显示本 Project 的。部署记录可点开看逐步日志，刷新页面后进行中的部署仍可继续查看。

部署结果不确定时先在这里核对再决定是否重试；清理状态含义见 [痕迹清除](/cleanup)。

## 常见问题

**客户端在运行，列表里却没有它**：确认当前范围（未归属的只在 Global 显示，归属其他 Project 的不在当前视图），清空筛选框，并在 [Logs](/logs) 中查看接入失败记录。

<Callout title="命令行等价" type="info">
  服务端 REPL 的 `ls`、`note`、`clean` 对应列出、备注和清理。REPL 没有 Project 范围：`ls` 总是列出全部客户端，也不能分配 Project。见 [服务端 REPL](/reference/repl)。
</Callout>
