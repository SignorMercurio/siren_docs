目标主机不是阿里云 ECS、云助手不可用，或你想在主机上手动操作时，登录主机安装客户端并连接服务端。

## 前置条件

目标主机能访问服务端主 TLS 端口（默认 `443`），且服务端已放行该主机的出口 IP：在 WebUI 用 [Allow access](/onboard/egress#allow-access)，或自行在服务端防火墙放行。服务端配置见 [前置条件与凭证](/server/prerequisites)。

## 安装客户端

Linux 需要 root，Windows 需要以管理员身份运行 PowerShell。

```bash tab="Linux"
curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh | sh
```

```powershell tab="Windows"
iwr -Uri 'https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.ps1' -UseBasicParsing | iex
```

安装脚本把 `siren` 和 `config.yaml` 装到 `/opt/siren`（Linux）或 `C:\Windows\Temp\siren`（Windows），不会启动客户端。

<Callout title="重装不会更新已有安装" type="warn">
  安装完好时再次运行安装脚本会跳过下载，不升级程序也不改配置（传了 `--server`、`--port` 时只改写这两个键）。安装损坏时才重新安装，并用包内 `config.yaml` 替换现有配置，手工改动会丢失。升级见 [升级与数据](/upgrade)。
</Callout>

## 启动客户端

```bash tab="Linux"
cd /opt/siren
./siren client -s <SIREN Server IP> -p 443
```

```powershell tab="Windows"
Set-Location C:\Windows\Temp\siren
.\siren.exe client -s <SIREN Server IP> -p 443
```

省略 `-s`、`-p` 时使用 `config.yaml` 中的 `server`、`port`。安装包预置的 `server` 是官方服务端 `47.111.170.208`，连接自建服务端必须传 `-s`；改过服务端连接端口时把 `443` 换成实际端口。

也可以安装时写入地址，之后启动不必传参：Linux 运行 `curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh | sh -s -- --server <SIREN Server IP> --port 443`，Windows 安装脚本对应参数为 `-Server`、`-Port`。

连接成功后客户端出现在 [Clients](/clients) 页。客户端是前台进程，应放到 systemd、nohup、Windows 计划任务等常驻环境中运行。

### 重连行为

客户端断线后自动重连，重试间隔为 8、16、30 秒，最多重试 10 次，之后客户端退出。启动后第一分钟内首次连接失败每 2 秒重试一次，便于放行后尽快上线。

## 卸载

手动安装的客户端用 **Clean** 卸载，它删除客户端侧的 SIREN 文件并终止进程，见 [痕迹清除](/cleanup)。
