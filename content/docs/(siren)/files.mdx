**Files** 页面（`#/files`）直接读写在线客户端主机上的真实文件系统：浏览目录、预览文本、下载文件或整个目录，以及向客户端上传文件。服务端上的报告和取证文件在 [Artifacts](/artifacts) 中管理，不在这里。

## 打开方式

- 侧栏 **Files**，在左上角的客户端下拉框中选择客户端。默认选中列表中的第一台。
- [Clients](/clients#行内操作) 页客户端行的 **More actions** → **Files**：跳到 Files 并选中这台客户端。

下拉框只列出当前范围内的在线客户端；Project 视图下只有该 Project 的客户端。切换 Project 或 Global 范围后，页面会清空选择并重新载入。

## 浏览目录

选中客户端后，左侧文件树从根目录开始：Linux 和 macOS 为 `/`，Windows 为 `C:\`。

- **Path**：输入路径后按 Enter 或点击 **Open**，文件树改从该路径开始。留空表示 `.`，即客户端进程的工作目录；相对路径也相对于这个目录。
- 点击目录展开，点击文件在右侧预览。
- 文件树上方的搜索框（**Search...**）只在已经载入的条目中按名称筛选，不会搜索尚未展开的目录。
- 刷新按钮重新读取文件树。

目录中先列子目录、再列文件，各自按名称排序。以点号开头的隐藏文件照常显示；指向目录的符号链接按目录显示。

每个目录最多列出 1,000 个条目。超出时，根目录顶部显示 `Showing first 1000 entries`，子目录在树中显示 `1000` 标记。截取按客户端读取目录的顺序进行，被省略的不一定是排序后的最后几项；要查看完整内容，请在 [Shell](/shells) 中用 `ls` 或 `find`。

## 预览

| 文件 | 预览方式 |
| --- | --- |
| 文本文件，不超过 5 MiB | 原样显示。带 BOM 的 UTF-16 文本会自动解码 |
| `.md`、`.markdown` | 渲染为 Markdown；有两个及以上标题时显示 **Contents** 目录 |
| 二进制文件（按文件开头判断） | 显示 `Preview not supported for binary files`，请下载后查看 |
| 超过 5 MiB 的文本 | 报错 `file too large for preview`，请下载后查看 |

Files 不预览图片，图片按二进制文件处理。

## 下载

- 文件：在预览区右上角点击 **Download** 图标，或在文件树中右键条目选择 **Download**。
- 目录：在文件树中右键目录选择 **Download**，客户端会把目录打包为 `<目录名>.tar.gz`；下载根目录 `/` 时文件名为 `root.tar.gz`。

| 限制 | 值 |
| --- | --- |
| 单个文件 | 100 MiB |
| 目录 | 其中普通文件合计不超过 100 MiB，压缩包本身也不超过 100 MiB，否则报错 `directory too large for download` |

打包目录时，隐藏文件照常包含；符号链接、设备文件等非普通文件，以及没有权限读取的文件会被跳过，不会报错。下载的文件只保存到你的浏览器，不会存入服务端 Artifacts；需要在服务端留存，见下文 [命令行](#命令行)，或把下载的文件上传到 [Artifacts](/artifacts)。

每次读取、下载或上传操作最多等待客户端 2 分钟。

## 上传

上传目标显示在页面右上角的 **Target** 中：打开某个路径后，Target 就是该路径；在文件树中展开某个目录后，Target 变为该目录，树中对应目录显示 **Target** 标记。

1. 确认客户端和 **Target**。
2. 点击 **Upload** 选择一个或多个文件，或把文件拖到页面任意位置松开。拖入时会显示目标目录。
3. 文件按顺序逐个上传，右上角显示 `Uploading N of M · <文件名>`。
4. 目标目录中已有同名文件时，弹出 **Overwrite client file?**，逐个选择 **Overwrite file** 或 **Skip file**。
5. 全部完成后提示上传、跳过和失败的数量；有文件上传成功时，文件树自动刷新。

| 规则 | 说明 |
| --- | --- |
| 单文件上限 | 100 MiB，超出的文件直接计为失败，其余文件继续上传 |
| 目录 | 不能上传目录，拖入目录时提示 `Directory upload is not supported. Drop files only.` |
| 文件名 | 不能包含 `/` 或 `\`；可以是 `.bashrc` 这类以点号开头的文件 |
| 新文件权限 | Linux 和 macOS 上为 `0644`；覆盖已有文件时保留原文件权限 |
| 并发 | 同一时间只能进行一批上传 |

<Callout title="直接修改客户端主机" type="warn">
  上传和覆盖会立即改写客户端主机上的文件，无法从 WebUI 撤销。操作前确认当前客户端、范围和 Target 目录。
</Callout>

## Files 不能做的事

Files 不提供删除、重命名、新建目录或修改权限。需要这些操作时，在 [Shell](/shells) 中执行。服务端文件的删除、重命名和新建目录在 [Artifacts](/artifacts) 中进行。

## 命令行

```bash tab="服务端 REPL"
>>> upload <Client ID> <Client file path>
```

```bash tab="本地模式"
./siren upload <file path>
```

**服务端 REPL** 的 `upload` 从在线客户端拉取一个文件到服务端：

- 保存到服务端工作目录下的 `uploads/client-<Client ID>/<文件名>`，即 Global 范围的 Artifacts 中。客户端属于某个 Project 时也一样，不会进入 Project 目录。
- 同名文件不会被覆盖，后续文件依次保存为 `<文件名>.1`、`<文件名>.2`……
- 只能拉取普通文件，单个文件最大 1 GiB。文件路径可以包含空格，例如 Windows 的 `C:\Program Files\...`。
- 保存成功后，服务端日志中出现 `artifact.upload.saved` 事件，带保存路径，可在 [Logs](/logs) 中查看。

**本地模式** 的 `./siren upload` 把当前主机上的文件上传到阿里云 OSS，对象路径为 `<oss.objectPath>/<文件名>`，安装包配置的前缀为 `tmp/siren_upload`，桶和地域由客户端配置的 `oss.bucketName`、`oss.region` 决定，见 [客户端配置](/reference/client-config)。使用前需要在该主机上设置 [OSS 凭证](/server/prerequisites#oss-凭证)。
