<Callout title="核心原则" type="info">
  SIREN 远程模式的 Recon、文件拉取和 Artifacts 浏览不依赖 OSS、MkDocs、云存储网关或极速同步组。以下基础设施均为可选，用于增强特定功能体验。
</Callout>

## 通用基础设施

| 基础设施 | 对应功能 | 必要性 |
| -------- | -------- | -------- |
| OSS Bucket 及访问凭证 | 本地模式 [信息收集报告上传](/recon)、[本地文件上传](/analysis/upload) | 仅使用本地模式 OSS 留存时需要 |
| 控制主机 | 客户端连接、WebUI、MCP、Artifacts、远程文件与调查工作流 | 远程模式必需 |
| tmux | 服务端 REPL 中的交互式 Shell 与 `air` 命令 | 仅使用 CLI Shell/AIR 时需要；WebUI Shell/AIR 不依赖 tmux |

## 内部环境额外基础设施

| 基础设施 | 对应功能 |
| -------- | -------- |
| SOAR 平台及访问凭证 | [云助手一键部署](/#内部环境通过云助手一键部署)、[自动放行受害主机](/index#手动部署)、[AccessKey 调查](/ak)、[MCP 工具 `get_alarm_detail`](/mcp#可用工具) |
