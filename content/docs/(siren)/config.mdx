SIREN 客户端与服务端均支持通过 YAML 配置文件进行自定义设置。

### 配置文件查找顺序

启动时，SIREN 会按以下顺序查找配置文件（找到即停止）：

1. 通过 `-c`/`--config` 参数指定的路径
2. 当前工作目录下的 `config.yaml`（客户端）或 `server_config.yaml`（服务端）
3. `./config/` 目录下的 `config.yaml` 或 `server_config.yaml`

<Callout title="敏感信息" type="warn">
  配置文件中**不包含**任何敏感凭证信息（如 AccessKey、API Key 等），所有凭证均通过环境变量设置，详见[凭证设置](/credential)。
</Callout>

## 客户端配置

```yaml title="config.yaml"
server: 127.0.0.1                           # 服务端地址
port: 443                                   # 服务端端口

recon:
  commandTimeout: 30                        # 命令执行超时时间
  user: true                                # 用户信息收集开关
  # ...other modules

oss:
  region: cn-hongkong                       # OSS Bucket Region
  bucketName: ir-transfer-station           # OSS Bucket 名称
  objectPath: tmp/siren_upload              # 本地 upload 文件上传路径
  docObjectPath: tmp/siren_upload/docs      # 本地 recon 文档上传路径

plugins:
  marketplace: https://example.com/plugins  # 插件市场地址
  jdump: true                               # 启用 jdump 插件

rules:                                      # 信息收集规则
  IPWhitelist: 140\.205\.11\.\d+|8\.147\.237\.0
  # ...other rules
```

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `server` | string | `127.0.0.1` | 远程模式下连接的服务端地址 |
| `port` | int | `443` | 远程模式下连接的服务端端口 |
| `recon.commandTimeout` | int | `30` | 信息收集和客户端远程命令执行的基础超时时间（秒）；MCP / AIR 慢命令建议服务端也设置相同值 |
| `recon.<module>` | bool | `true` | 各信息收集模块的开关（如 `user`、`process`、`network` 等），完整列表见[信息收集模块](/recon#信息收集模块) |
| `oss.region` | string | - | OSS Bucket 所在地域 |
| `oss.bucketName` | string | - | OSS Bucket 名称 |
| `oss.objectPath` | string | `tmp/siren_upload` | 本地 `siren upload` 的 OSS 路径前缀 |
| `oss.docObjectPath` | string | `tmp/siren_upload/docs` | 本地 `siren recon` 文档上传的 OSS 路径前缀 |
| `plugins.marketplace` | string | - | 插件市场 URL，用于下载和更新插件 |
| `plugins.<name>` | bool | - | 启用或禁用指定的 command 类型插件 |
| `rules` | map | - | 信息收集规则，值为正则表达式 |

<Callout title="关于 rules" type="info">
  `rules` 用于在信息收集结果中标记或过滤特定内容。例如 `IPWhitelist` 可以在网络连接信息中标识已知的白名单 IP 地址，减少排查噪音。规则值支持正则表达式，支持白名单（过滤已知正常项）和黑名单（高亮可疑项）两种类型。
</Callout>

## 服务端配置

```yaml title="server_config.yaml"
listen: 0.0.0.0                                 # 客户端 TLS 服务监听地址
port: 443                                       # 客户端 TLS 服务监听端口
cert: certs/cert.pem                            # TLS 证书路径
key: certs/key.pem                              # TLS 密钥路径

webui:                                          # Web 控制台
  enabled: true                                 # 是否启用 WebUI
  listen: 0.0.0.0                               # 共享 HTTP 监听地址
  port: 8080                                    # 监听端口（WebUI 与 MCP 共享）
  userDBPath: data/users.db                     # 可选：WebUI 用户数据库路径
  dossierDir: /opt/siren/dossier                # 可选：Dossier 编辑器文件目录
  projectsBaseDir: /opt/siren/projects          # 可选：WebUI Project 目录创建基准路径

mcp:
  enabled: true                                 # 是否启用 MCP 服务
  cmdBlacklist:                                 # MCP run 命令黑名单（正则表达式）
    - '(?:^|[;|&\n]\s*)(?:sudo\s+)?rm(?:\s|$)'
    - '(?:^|[;|&\n]\s*)(?:sudo\s+)?find(?:\s|$)[^;|&\n]*\s-delete(?:\s|$)'
    - '(?:^|[;|&\n]\s*)(?:sudo\s+)?dd(?:\s|$)[^;|&\n]*\bof=/dev/(?:sd|hd|vd|xvd|nvme|mapper|dm-|loop|md|ram)'
    - '(?:^|[;|&\n]\s*)(?:sudo\s+)?systemctl\s+(stop|disable|mask|restart|reload)(?:\s|$)'
    - '(?:^|[;|&\n]\s*)(?:sudo\s+)?(?:useradd|usermod|userdel|groupadd|groupmod|groupdel)(?:\s|$)'
    # ...more destructive-action patterns

air:
  # 服务端 REPL air 命令与 WebUI 浏览器终端的默认 Provider；也可逐会话在页面上选择
  provider: claude                             # claude / codex
  prompt: 启动安全应急响应，UID：%s，...        # 告警事件模式的 prompt 模板
  customPromptPrefix: 在 SIREN Client %d 上...  # 自定义 prompt 模式的前缀
  # providers.<name> 同时用于 SIREN 上下文 AIR（注入 MCP）与 Manual 裸终端
  providers:
    claude:
      cliPath: claude                          # Claude Code CLI 路径
      strictMCPConfig: true                    # 仅 WebUI 终端：注入 --mcp-config 时是否只暴露 SIREN MCP
      args: []                                 # 额外 Claude CLI 参数
    codex:
      cliPath: codex                           # Codex CLI 路径
      args: []                                 # 额外 Codex CLI 参数
```

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `listen` | string | `0.0.0.0` | 客户端 TLS 服务监听地址 |
| `port` | int | `443` | 客户端 TLS 服务监听端口 |
| `cert` | string | `certs/cert.pem` | TLS 证书文件路径 |
| `key` | string | `certs/key.pem` | TLS 私钥文件路径 |
| `webui.enabled` | bool | `true` | 是否启用 [Web 控制台](/webui)。关闭后若 `mcp.enabled` 仍为 `true`，`/mcp` 会继续在共享端口上提供服务 |
| `webui.listen` | string | `0.0.0.0` | WebUI 与 MCP 共享的监听地址；只要 `webui.enabled` 或 `mcp.enabled` 有一个启用就会启动监听 |
| `webui.port` | int | `8080` | WebUI 与 MCP 共享的监听端口，MCP 通过 `/mcp` 子路径暴露 |
| `webui.userDBPath` | string | `data/users.db` | WebUI 用户 SQLite 数据库路径（相对路径基于启动 CWD） |
| `webui.dossierDir` | string | -（示例配置为 `/opt/siren/dossier`） | Dossier 编辑器文件目录，可位于服务端工作目录外；左侧 Dossier 入口默认打开该目录下的 `report.md`。默认为空，留空、目录不可用或默认报告不可访问时，WebUI 会提示错误。详见 [Dossier 配置](/dossier/config) |
| `webui.projectsBaseDir` | string | `""`（服务端当前工作目录） | WebUI Project 目录创建基准路径。创建 Project 时只允许在该目录下创建一个 basename 子目录；Project 重命名不会移动目录，删除 Project 只删除元数据并保留目录文件 |
| `mcp.enabled` | bool | `true` | 是否启用 [MCP 服务](/mcp)，独立于 `webui.enabled` |
| `mcp.cmdBlacklist` | list | 见 [MCP 集成](/mcp#命令黑名单) | MCP `run` 工具的命令黑名单，值为正则表达式列表 |
| `air.provider` | string | `claude` | AIR 历史会话与服务端 REPL `air` 命令默认使用的 Provider，可选 `claude` 或 `codex`；WebUI 终端页面中也可在每次启动会话时选择 |
| `air.prompt` | string | - | 告警事件模式下的 prompt 模板，依次填入 `%s` UID、`%s` 安全中心告警 ID、`%d` Client ID（告警 ID 即 `air` 命令的 Security Center Alert ID，详见 [Agentic 应急响应](/air)） |
| `air.customPromptPrefix` | string | - | 自定义 prompt 模式下的前缀（支持 `%d` Client ID） |
| `air.providers.claude.cliPath` | string | `claude` | Custom / Event / Resume 模式的 Claude Code CLI 路径；服务端 REPL 的 `air` 命令也使用该配置 |
| `air.providers.claude.strictMCPConfig` | bool | `true` | 仅作用于 WebUI 终端：SIREN 注入 `--mcp-config` 时，`true` 只暴露 SIREN MCP 服务，`false` 同时加载环境已有的 MCP 配置；tmux REPL 忽略此项 |
| `air.providers.claude.args` | list | `[]` | 传递给 Claude CLI 的额外参数 |
| `air.providers.codex.cliPath` | string | `codex` | Custom / Event / Resume 模式的 Codex CLI 路径 |
| `air.providers.codex.args` | list | `[]` | 传递给 Codex CLI 的额外参数 |

> WebUI 浏览器终端复用上面的 `air.providers.<name>`（Manual 模式取 `cliPath` + `args`），无需单独配置；Provider 在每次启动会话时选择，默认 Claude。它和浏览器 Shell 一样只受 WebUI 全局鉴权保护。

<Callout title="v2.12.0 AIR 配置更新" type="info">
  AIR 改为浏览器内嵌终端后，SIREN 不再覆盖大模型 CLI 的行为：`air.providers.claude` 的 `model` / `effort` / `allowedTools` 与 `air.providers.codex` 的 `model` / `effort` / `sandbox` / `approval` / `mcpApproval` / `enabledTools` 均已移除，改由 Claude Code / Codex 自身配置决定。如需对 Claude 限定拒绝调用的工具，可选配 `air.providers.claude.disallowedTools`。WebUI 浏览器终端不再有独立配置块：它复用 `air.providers.<name>` 并与浏览器 Shell 一样只受 WebUI 全局鉴权保护，因此原 `agentTerminal.*`（`enabled` / `requireAuth` / `allowWithoutAuth` / `defaultProvider` / `replayBufferBytes` / `providers`）已全部移除。
</Callout>

<Callout title="v1.x 升级提示" type="warn">
  v2.0.0 合并了 MCP 与 WebUI 端口，顶层 `mcpPort` 字段与 `--mcp-port` 参数已移除。升级后的配置示例如上，`mcpPort` 如有残留不会报错但会被忽略。
</Callout>
