**Logs** 页面显示服务端内存中最近的运行日志，不必登录控制主机就能看到客户端接入失败、登录失败、Shell 会话、AIR 与 MCP 报错等事件。

这些记录与服务端终端输出的日志相同，同样受 `logging.level` 过滤；`logging.output` 设为 `none` 时页面仍照常保留。服务端 REPL 的命令回显（如 `run`、`info` 的输出）不是日志，不会出现在这里。Logs 不区分 Project，任何范围下都显示全部日志。

## 查看与过滤

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 不区分大小写的子串匹配，覆盖日志正文和所有字段值（如 Client ID、IP、事件名、`audit_id`），不匹配字段名 |
| **All** / **Debug** / **Info** / **Warning** / **Error** | 级别可多选；**All** 表示不限级别 |
| **All components** 下拉框 | 按组件过滤，如 `server`、`client`、`webui`、`mcp`、`air`、`recon`、`artifact`、`port_forward` |
| **Live** / **Paused** | **Live** 持续拉取新日志，**Paused** 停止拉取 |
| 复制、下载按钮 | 把当前列表复制为纯文本或下载为文件 |

点击一行可展开完整 JSON；行内截断的字段值在展开、复制和下载中保持完整。列表最多显示最近 2,000 条。

## 保留范围

日志只保存在服务端内存中，条数由 `logging.bufferSize` 控制（默认 5000）：

- 服务重启后清空。
- 写满后淘汰最早的记录。
- 设为 `0` 或负数则不保留，页面显示 `Server log retention is off`。修改后需重启服务端。

SIREN 不写日志文件；长期留存见 [日志格式与留存](/reference/server-config#日志格式与留存)，`logging.*` 各键见 [服务端配置](/reference/server-config#logging)。

## 常用审计事件

结构化日志带有稳定的 `event` 字段，在搜索框输入事件名即可筛选：

| 要追查 | 事件 | 主要字段 |
| --- | --- | --- |
| 客户端接入与断开 | `client.connected`、`client.disconnected`、`client.handshake_failed` | `client_id`、`remote_addr`、`os`、`project` |
| WebUI 登录 | `auth.login.success`、`auth.login.failed`、`auth.login.rate_limited`、`auth.logout.success` | `user`、`remote_ip` |
| 浏览器 Shell | `shell.session.started`、`shell.session.ended`、`shell.session.request_failed` | `user`、`client_id`、`project`、`duration_ms`、结束原因 `reason` |
| MCP 命令执行 | `mcp.run.requested`、`mcp.run.finished` | `audit_id`、`command`、`client_id`、`outcome` |
| REPL 拉取文件 | `artifact.upload.saved` | `client_id`、`path` |
| WebUI 请求 | `webui.request.completed` 等 | `request_id`、`user`、`route` |

Shell 会话只记录谁在何时对哪台客户端打开、持续多久，不记录输入和输出。

WebUI 只记录失败的请求、成功的修改类操作和慢请求，不记录查询参数和请求正文。排查某次 WebUI 报错时，在浏览器开发者工具中找到响应头 `X-Request-ID`，再在 Logs 中搜索它。

### MCP 命令审计

每次 `run` 调用有两条共享同一 `audit_id` 的记录：执行前的 `mcp.run.requested` 和结束时的 `mcp.run.finished`，被拦截、超时或执行失败的调用也有完成记录，由 `outcome` 说明结果；`run_batch` 中每台主机各有一个 `audit_id`。

选择 `mcp` 组件后搜索命令片段、Client ID、outcome 或 `audit_id`。日志含完整命令但不含输出；输出通过 MCP 的 `read_run_result` 按 `audit_id` 回读，只保留 60 分钟。字段含义见 [命令审计](/reference/mcp#审计日志)。

<Callout title="日志包含敏感信息" type="warn">
  任何已登录账号都能查看全部日志，包括来访 IP、登录用户名、客户端地址和 MCP `run` 的完整命令。可调低 `logging.bufferSize` 或设为 `0` 关闭该页面，见 [Logs 包含敏感信息](/server/security#logs-包含敏感信息)。
</Callout>
