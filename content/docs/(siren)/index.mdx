SIREN 由一台控制主机上的 SIREN Server 和装在目标主机上的客户端组成。日常操作都在浏览器里的 Web 控制台完成：接入主机、打开 Shell、运行 Recon、启动 Agentic IR、查看证据和编辑报告。

按下面四步可以完成第一次排查。

<Callout title="内部预部署环境" type="info">
  内部环境通常已完成控制主机、SOAR 凭证和外部工具配置。已有可用控制主机时，直接从第 2 步开始；内部地址见 [内部文档](https://aliyuque.antfin.com/ykozrq/puiz2d/mktg38agsx5bfz9v)。
</Callout>

<Steps>
<Step>

### 部署服务端

在控制主机上用 root 运行安装脚本，创建 Web 控制台账号，并把两个不同的 MCP 凭证写入工作目录下的 `.env`：

```bash title="控制主机"
curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren_server.sh | sh
cd /opt/siren
./siren_server user add admin
umask 077
cat > .env <<EOF
SIREN_MCP_ADMIN_TOKEN=$(openssl rand -hex 32)
SIREN_MCP_RAVEN_TOKEN=$(openssl rand -hex 32)
EOF
```

然后在 tmux 中启动服务端。服务端的终端一旦关闭，服务端也会退出，所以不能直接交给 systemd：

```bash title="控制主机"
tmux new -s siren
cd /opt/siren && ./siren_server
```

默认配置启用了 MCP，缺少任一凭证或两者相同时服务端会拒绝启动。证书、`webui.publicURL`、`egress.rules` 和各项依赖见 [安装服务端](/server) 与 [前置条件与凭证](/server/prerequisites)。

</Step>
<Step>

### 登录 Web 控制台

浏览器打开 `https://<SIREN Server 域名>`，用刚创建的账号登录。左侧导航按应急流程分组：**Clients** 和 **Agentic IR** 用于响应，**Shells**、**Files**、**Investigations** 用于手工排查，**Artifacts** 和 **Reports** 保存证据与报告。各页面的位置和通用操作见 [WebUI 导览](/webui)。

需要按事件隔离主机和取证文件时，先在侧栏顶部的范围菜单中创建并切换到一个 [Project](/projects)。之后接入的主机会自动归属到该 Project。

</Step>
<Step>

### 接入第一台主机

打开 **Clients** 页面，在 **Provisioning** 区域选择接入方式：

- **阿里云 ECS**：选择 **Deploy SIREN**，填写 Alibaba Cloud UID，每行一个 Instance ID。SIREN 通过云助手安装客户端、放行网络，并以客户端实际连上服务端为成功标准。详见 [一键部署](/onboard/provisioning)。
- **其他主机**：先用 **Allow access** 放行目标主机的公网出口 IP，再登录目标主机运行安装脚本并启动客户端。详见 [手动安装客户端](/onboard/manual)。

客户端连接后会出现在 Clients 列表中。不同场景的选择建议见 [选择接入方式](/onboard)。

</Step>
<Step>

### 开始排查

在 Clients 列表中找到目标主机，可以：

- 打开行菜单选择 **Recon**，在 Investigations 中选择 Profile 后点击 **Start Recon**，收集系统基线快照。详见 [Recon](/recon)。
- 进入 **Agentic IR**，选择 Provider 和 **Event** 模式，填写 UID 与告警 ID 后启动，让 Agent 通过 SIREN 工具在主机上排查。详见 [Agentic 应急响应](/air)。
- 进入 **Shells** 打开交互式终端，或在 **Files** 中浏览和下载可疑文件。

结果保存在 **Artifacts** 中。排查结束后，按 [痕迹清除](/cleanup) 和 [恢复出站规则](/restore-egress) 收尾。

</Step>
</Steps>

## 本地模式

目标主机无法连接控制主机，或要求数据不离开主机时，可以只在目标主机上安装客户端并直接运行 Recon，不需要服务端：

```bash tab="Linux"
curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh | sh
cd /opt/siren
./siren recon
```

```powershell tab="Windows"
iwr -Uri 'https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.ps1' -UseBasicParsing | iex
Set-Location C:\Windows\Temp\siren
.\siren.exe recon
```

本地模式只能使用 Recon、进程分析、上传和清理等客户端命令，没有 Web 控制台、Shell、Agentic IR 和 Project。详见 [Recon](/recon)。
