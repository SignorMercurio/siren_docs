按本页顺序操作，可以完成 SIREN Server 和客户端安装，并开始第一次排查。

## 模式选择

SIREN 支持本地模式和远程模式。多数应急场景建议使用远程模式；只有目标主机网络隔离，或明确要求数据不离开目标主机时，才优先使用本地模式。

| 模式 | 适合场景 | 你需要准备 |
| --- | --- | --- |
| 本地模式 | 单机、离线、无法连接控制主机，或数据不允许传出 | 登录目标主机并安装 SIREN |
| 远程模式 | 多主机排查、统一管理客户端，或需要 Web 控制台、Shell、Files、Artifacts、AIR、Project | 一台控制主机，目标主机能够访问控制主机 |

<Callout title="选择建议" type="info">
  如果你不确定该选哪种模式，先使用远程模式。远程模式可以通过 SIREN Server 管理多个客户端，并同时使用服务端 REPL、Web 控制台和 MCP。
</Callout>

## 服务端部署（可选）

仅远程模式需要部署服务端。本地模式可以跳过本节，直接进入“客户端部署”。

<Callout title="内部预部署环境" type="info">
  内部环境通常已完成控制主机、SOAR 凭证和外部工具配置。已有可用控制主机时，可以直接从“客户端部署”开始；内部地址见 [内部文档](https://aliyuque.antfin.com/ykozrq/puiz2d/mktg38agsx5bfz9v)。
</Callout>

<Accordions>
  <Accordion title="服务端部署">
    准备一台控制主机，并确认以下条件：

    - 目标主机和操作者都能够访问控制主机的主 TLS 端口，默认是 `443`
    - 首次安装时控制主机需要提供 `openssl`，用于生成该主机独有的初始自签证书
    - 如需在服务端 REPL 中使用交互式 Shell 或 `air` 命令，控制主机需安装 tmux；只使用 Web 控制台的 Shell/AIR 时不需要 tmux

    使用 root 账号复制并运行下面的命令：

    ```bash title="控制主机"
    curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren_server.sh | sh
    ```

    服务端安装包不包含 TLS 私钥。首次安装会在控制主机的 `/opt/siren/certs/` 生成仅覆盖 `localhost` 和 `127.0.0.1` 的初始自签证书；再次运行安装器升级时，已有 `server_config.yaml` 和证书均会保留。需要通过公开域名访问 WebUI 时，请在启动前换成覆盖该域名且受浏览器信任的证书，并更新 `server_config.yaml` 中的 `cert` / `key`。

    首次启动前，创建 Web 控制台账号。随后启动服务端，并保持进程运行：

    ```bash title="控制主机"
    cd /opt/siren
    ./siren_server user add admin
    ./siren_server
    ```

    SIREN Server 默认在同一个 `443` TLS 端口接收客户端连接，并提供 [Web 控制台](/webui) 和 [MCP 服务](/mcp)。浏览器访问需要证书覆盖服务端域名；使用 WebUI AIR 时，还要将 `webui.publicURL` 设置为该域名的 HTTPS Origin。详见 [配置文件](/config)。

    <Callout title="按需配置" type="info">
      需要在 Web 控制台中编辑报告时，部署 [Dossier](/dossier/deploy)；需要按事件隔离客户端和取证目录时，配置 `webui.projectsBaseDir` 并使用 [Projects](/webui#projects)。这些配置不影响客户端连接和 Recon。
    </Callout>

  </Accordion>
</Accordions>


## 客户端部署

<Callout title="Windows 系统要求" type="info">
  Windows 客户端最低支持 Windows 7 SP1 或 Windows Server 2008 R2 SP1，并需要 PowerShell 5.1。安装脚本会自动为旧系统选择兼容包，无需手工判断系统版本。
</Callout>

### 内部环境：通过云助手一键部署

<Callout title="前置条件" type="info">
  目标主机需要是阿里云 ECS，且云助手状态正常。控制主机还需要配置 [SOAR 平台访问凭证](/credential#设置-soar-平台访问凭证)；内部预部署环境通常已完成该配置。
</Callout>

在 SIREN Server 中运行：

```bash title="SIREN Server"
>>> deploy <Alibaba Cloud UID> <ECS Instance ID> [Public IP]
```

如需部署多台 ECS，使用批量部署命令。单次支持 2-20 台：

```bash title="SIREN Server"
>>> deploy-batch <Alibaba Cloud UID> <instanceId[,publicIp[,note]]>...
```

目标格式为 `instanceId[,publicIp[,note]]`。只填写备注时，使用 `instanceId,,note`。

部署命令会完成以下操作：

1. 从 SOAR 平台读取目标主机的地域、操作系统和出口 IP
2. 放行目标主机访问 SIREN Server
3. 校验并安装匹配系统架构的 SIREN 客户端；已有健康安装会直接复用
4. 最多等待 30 秒，客户端连接成功后返回实际 Client ID

看到 `connected as client #<Client ID>` 才表示部署成功。安装失败、启动失败或等待超时都会返回明确错误。

<Callout title="共享出口 IP" type="info">
  多个部署目标共享同一个出口 IP 时，SIREN 会使用安装后返回的客户端稳定身份精确关联每台主机，不会按 IP 猜测。稳定身份缺失、冲突或来源 IP 不一致时，目标会进入 `manual_required`；请在 Clients 列表中核对后手工设置 Project 和 Note，不要直接重复部署。
</Callout>

<Callout title="出口 IP 获取失败时" type="info">
  少数情况下 SOAR 无法返回目标主机的公网出口 IP。此时可在第三个参数手动传入出口 IP，SIREN 会跳过自动探测、直接使用该 IP 放行访问：

  ```bash title="SIREN Server"
  >>> deploy user123 i-1234567890abcdef0 203.0.113.10
  ```

  目标主机出口 IP 可以在目标主机上通过 `curl ifconfig.co/ip` 获取。
</Callout>

### 手动部署

登录目标主机，复制并运行对应系统的安装命令。Linux 需要 root 权限，Windows 需要以管理员身份打开 PowerShell。手动安装不会自动启动客户端。

```bash tab="Linux"
curl -fsSL https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh | sh
```

```powershell tab="Windows"
iwr -Uri 'https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.ps1' -UseBasicParsing | iex
```

#### 本地模式

安装完成后，在目标主机运行一次 Recon：

```bash tab="Linux"
cd /opt/siren
./siren recon                 # default Profile
./siren recon --profile quick # 跳过 file 模块
```

```powershell tab="Windows"
Set-Location C:\Windows\Temp\siren
.\siren.exe recon --profile quick
```

#### 远程模式

先确保 SIREN Server 的客户端连接端口允许目标主机的出口 IP 访问。内部环境可以在 SIREN Server 中运行：

```bash title="SIREN Server"
>>> allow <Victim IP>
```

目标主机出口 IP 可以通过 `curl ifconfig.co/ip` 获取。放行后，在目标主机启动客户端：

```bash tab="Linux"
cd /opt/siren
./siren client -s <SIREN Server IP> -p 443
```

```powershell tab="Windows"
Set-Location C:\Windows\Temp\siren
.\siren.exe client -s <SIREN Server IP> -p 443
```

如果修改过客户端连接端口，请将 `443` 替换为实际端口。保持客户端进程运行，SIREN Server 出现 Client ID 后即可开始排查。

## 开始第一次排查

远程模式下，客户端连接后可以从 Web 控制台或服务端 REPL 开始排查。本地模式的 Recon 结果会直接显示在目标主机终端中。

```text tab="Web 控制台"
打开 https://<SIREN Server hostname>
进入 Clients，选择客户端
进入 Investigations，启动 Recon
```

```bash tab="服务端 REPL"
>>> ls
>>> recon <Client ID> [Profile]
```
