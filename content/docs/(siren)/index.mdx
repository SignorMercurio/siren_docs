本页按最短路径完成 SIREN 启动：先选择运行模式，再部署服务端和客户端，最后开始第一次排查。

## 模式选择

SIREN 支持本地模式和远程模式。多数应急场景建议使用远程模式；只有目标主机网络隔离，或明确要求数据不离开目标主机时，才优先使用本地模式。

| 模式 | 适合场景 | 你需要准备 |
| --- | --- | --- |
| 本地模式 | 单机、离线、无法连接控制主机，或数据不允许传出 | 登录目标主机并运行 `siren` |
| 远程模式 | 多主机排查、统一管理客户端，或需要 Web 控制台、Shell、Files、Artifacts、AIR、Project | 一台控制主机，目标主机能够访问控制主机 |

<Callout title="选择建议" type="info">
  如果你不确定该选哪种模式，先使用远程模式。远程模式可以通过 SIREN Server 管理多个客户端，并同时使用服务端 REPL、Web 控制台和 MCP。
</Callout>

## 服务端部署（可选）

仅远程模式需要部署服务端。本地模式可以跳过本节，直接在目标主机运行 `./siren recon`。

<Callout title="内部预部署环境" type="info">
  内部环境通常已完成控制主机、SOAR 凭证和外部工具配置。已有可用控制主机时，可以直接从“客户端部署”开始；内部地址见 [内部文档](https://aliyuque.antfin.com/ykozrq/puiz2d/mktg38agsx5bfz9v)。
</Callout>

<Accordions>
  <Accordion title="服务端部署">
    准备一台控制主机，并确认以下条件：

    - 目标主机能够访问控制主机的客户端连接端口，默认是 `443`
    - 操作者能够访问控制主机的 HTTP 端口，默认是 `8080`
    - 如需在服务端 REPL 中使用交互式 Shell 或 `air` 命令，控制主机需安装 tmux；只使用 Web 控制台的 Shell/AIR 时不需要 tmux

    在控制主机上运行：

    ```bash title="控制主机"
    (wget -q -O - https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren_server.sh || curl -s https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren_server.sh) | sh
    ```

    启动服务端：

    ```bash title="控制主机"
    cd /opt/siren
    ./siren_server
    ```

    SIREN Server 默认使用 `443` 作为客户端 TLS 连接端口，同时在 `8080` 提供 [Web 控制台](/webui) 和 [MCP 服务](/mcp)。可通过 `-p` 参数或配置文件修改客户端连接端口。

    部署到公网或共享网络前，先创建 Web 控制台账号。空用户数据库会禁用 Web 控制台鉴权，适合本地测试，但不适合暴露在共享网络中。

    ```bash title="控制主机"
    ./siren_server user add admin
    ```

    <Callout title="按需配置" type="info">
      需要在 Web 控制台中编辑报告时，部署 [Dossier](/dossier/deploy)；需要按事件隔离客户端和取证目录时，配置 `webui.projectsBaseDir` 并使用 [Projects](/webui#projects)。这些配置不影响客户端连接和 Recon。
    </Callout>

  </Accordion>
</Accordions>


## 客户端部署

### 内部环境：通过云助手一键部署

<Callout title="前置条件" type="info">
  目标主机需要是阿里云 ECS，且云助手状态正常。控制主机还需要配置 [SOAR 平台访问凭证](/credential#设置-soar-平台访问凭证)；内部预部署环境通常已完成该配置。
</Callout>

在 SIREN Server 中运行：

```bash title="SIREN Server"
>>> deploy <Alibaba Cloud UID> <ECS Instance ID> [Public IP]
```

如需部署多台 ECS，使用批量部署命令。每个目标可以写成 `instanceId`、`instanceId,publicIp` 或 `instanceId,publicIp,note`；只填写备注时使用 `instanceId,,note`。单次支持 2-20 台：

```bash title="SIREN Server"
>>> deploy-batch <Alibaba Cloud UID> <instanceId[,publicIp[,note]]>...
```

`deploy` 和 `deploy-batch` 会完成以下动作：

1. 从 SOAR 平台读取目标主机的地域、操作系统和出口 IP
2. 放行目标主机访问 SIREN Server
3. 校验并安装匹配系统架构的 SIREN 客户端；已有健康安装会直接复用
4. 最多等待 30 秒，客户端连接成功后返回实际 Client ID

SOAR playbook 执行完成不等于客户端已经上线。只有目标客户端连接到当前 SIREN Server，部署才会显示成功；安装或启动命令返回非零退出码时会立即显示命令输出，等待超时或只能手工确认客户端时也会返回明确错误。

<Callout title="共享出口 IP" type="warning">
  如果多个进行中的部署目标使用同一个出口 IP，SIREN 会继续执行部署，但不会猜测新连接属于哪台主机。请在 Clients 列表中核对客户端后手工设置 Project 和 Note，不要直接重复部署。
</Callout>

<Callout title="出口 IP 获取失败时" type="info">
  少数情况下 SOAR 无法返回目标主机的公网出口 IP。此时可在第三个参数手动传入出口 IP，SIREN 会跳过自动探测、直接使用该 IP 放行访问：

  ```bash title="SIREN Server"
  >>> deploy user123 i-1234567890abcdef0 203.0.113.10
  ```

  目标主机出口 IP 可以在目标主机上通过 `curl ifconfig.co/ip` 获取。
</Callout>

### 手动部署

登录目标主机后，执行安装脚本：

```bash tab="Linux"
(wget -q -O - https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh || curl -s https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.sh) | sh
```

```bash tab="Windows"
powershell -ExecutionPolicy Bypass -Command "iwr -Uri 'https://oss-siren.oss-cn-hongkong.aliyuncs.com/get_siren.ps1' -UseBasicParsing | iex"
```

如果使用本地模式，安装后直接运行：

```bash tab="Linux"
./siren recon
```

```powershell tab="Windows"
.\siren.exe recon
```

如果使用远程模式，需要先允许目标主机出口 IP 访问 SIREN Server。内部环境可以在 SIREN Server 中运行：

```bash title="SIREN Server"
>>> allow <Victim IP>
```

目标主机出口 IP 可以通过 `curl ifconfig.co/ip` 获取。随后以客户端模式连接服务端：

```bash tab="Linux"
./siren client -s <Server IP> -p <Server Port>
```

```powershell tab="Windows"
.\siren.exe client -s <Server IP> -p <Server Port>
```

## 开始第一次排查

客户端连接后，可以从 Web 控制台、服务端 REPL 或本地命令开始排查。

```text tab="Web 控制台"
打开 http://<SIREN Server IP>:8080
进入 Clients，选择客户端
进入 Investigations，启动 Recon
```

```bash tab="服务端 REPL"
>>> ls
>>> recon <Client ID>
```

```bash tab="本地模式"
./siren recon
```
