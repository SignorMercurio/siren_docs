Web 控制台是使用 SIREN 的主要方式，浏览器直接访问 `https://<SIREN Server 域名>`。安装与端口见 [安装服务端](/server)，账号与鉴权见 [账号与安全边界](/server/security)。

![Web 控制台的 Clients 页：左侧为按应急流程分组的导航，右侧为客户端列表和 Provisioning 面板](../../img/webui-clients.png)

## 导航

左侧导航按应急流程分为四组：

| 分组 | 页面 | 用途 |
| --- | --- | --- |
| **Respond** | [Clients](/clients)、[Agentic IR](/air) | 在线客户端列表与 **Provisioning**（部署、放行、出站恢复）；AI 辅助排查 |
| **Tools** | [Shells](/shells)、[Files](/files)、[Investigations](#investigations) | 交互式终端；客户端文件浏览和上传下载；Recon / 进程分析 / AccessKey 调查 |
| **Evidence** | [Artifacts](/artifacts)、[Reports](/reports) | 服务端证据目录；当前范围内的 Dossier 应急报告 |
| **System** | [Logs](/logs) | 服务端运行日志与 MCP 命令审计 |

导航之外还有两个入口：

- **范围菜单**：侧栏顶部的 **Project scope**，在 Global 和各 Project 视图之间切换，**Manage projects** 打开 [Projects](/projects) 页面。
- **账号菜单**：侧栏左下角，提供 [Settings](#settings) 和退出登录。

每个页面、工具标签、AIR 会话和选中文件都有自己的 URL，可以刷新或分享。

## Investigations

需要等待结果的调查工具，分为 **AccessKey**、**Recon** 和 **Process Analysis** 三个标签，切换标签不丢失已有结果。见 [AccessKey 调查](/ak)、[自动化信息收集](/recon) 和 [进程分析](/process)。

## Settings

从左下角的账号菜单打开，分两部分：

- **Preferences**：只保存在当前浏览器，不跟随账号同步。
  - 启动时的 Project 范围：沿用上次的范围，或每次从 Global 开始。
  - Agentic IR 默认 Provider：沿用上次，或固定 Codex / Claude / Pi / Qoder，单次会话仍可临时切换。
  - Agentic IR 默认界面：沿用上次，或固定 GUI / Terminal。
  - Clients 列表刷新频率。
- **Server**：只读的版本号、鉴权状态与当前用户、Dossier 目录，以及每个 AIR Provider 实际可用的界面；Provider 不可用时显示原因。
