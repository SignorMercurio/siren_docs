Dossier Markdown 是普通 Markdown 正文加少量报告专用的 `:::` 结构块，不是 MDX，不支持 JSX 组件。编辑器 **帮助** 中有同一份语法说明和结构块模板。创建、编辑和导出见 [报告](/reports)。

## Frontmatter

只有文件开头的 `---` 块是 frontmatter，正文中后续的 `---` 是普通分隔线：

```md
---
date: 20261008
sir-seq: 01
version: 1.0
client: 示例客户
---
```

四个字段同步到封面、页眉和页脚，Reports 页要求它们齐全，见 [什么算一份报告](/reports#什么算一份报告)。`cover-meta` 和 `rev` 的单元格可以引用这些字段：

| 写法 | 输出（`date: 20261008`） |
| --- | --- |
| `{date}` | `20261008` |
| `{date:slash}` | `2026/10/08` |
| `{date:slash-pad}` | `2026 / 10 / 08` |
| `{sir-seq}`、`{version}` | 对应字段值 |

## 章节与标题

```md
## 事件概述 / Event Overview
### 事件结论 / Incident Conclusion {page slot=2.3}
#### 覆盖说明 / Coverage Notes
```

- `##` 是章，`###` 是节，`####` 是嵌套小节。
- 英文标题可选，写成 `中文 / English`，`/` 两侧各留一个空格。
- `###` 末尾加 `{page}`，该节从新页开始；`{page slot=3.4}` 同时固定节号。`{page}` 写在 `####` 上会被忽略并警告；没有 `page` 的 `slot=` 只是标题文字。
- 标题以点分编号开头（`### 3.1 排查过程`）会固定该节编号；单独的整数（`#### 7 月早期失陷`）仍是标题文字。
- 编辑器底部 **目录** 按 `##`、`###`、`####` 和 `::: phase`（作为三级条目）生成大纲。

## 分页

内容按固定页高自动分页。长列表、表格、时间线和阶段任务列表可以跨页拆分；图片、资产卡、callout、键值块、阶段标题和代码块放不下时整体移到下一页。

`{break}` 单独一行强制换页：

```md
上一页的最后一段正文。

{break}

![全页图示](IR-20261008-01.assets/diagram.png){size=full}
```

`{gap}` 单独一行插入留白，`size` 可选 `sm`、`md`（默认）、`lg`，其他值按 `md` 处理并警告。落在页首的留白会被折叠。

```md
第一段正文。

{gap size=lg}

第二段正文。
```

实际分页用 [校样](/reports#校样) 检查。

## 正文

````md
- [x] 已完成动作
- [/] 进行中动作
- [ ] 未开始动作

- 父级排查项
  - 子项用两个空格缩进

1. 第一项
2. 第二项

这是一段包含 **重点**、*斜体*、`code` 和 [链接](https://example.com) 的正文。

> 引用客户原始描述、处置备注或需要单独标示的限制说明。

| 字段 | 内容 |
| --- | --- |
| 入口 | 控制台访问密钥 |

```sh
aliyun sts GetCallerIdentity
```
````

- 列表用 `-`，嵌套缩进两个空格；有序列表写 `1.` 或 `1)`。任务复选框 `[x]` 已完成、`[/]` 进行中、`[ ]` 未开始。
- 斜体写 `*斜体*` 或 `_斜体_`；单词内部的 `_`（如 `snake_case`）不算斜体。
- 表格需要表头下的分隔行（`| --- |`），`:---:`、`---:` 设置对齐。
- 链接可以是相对路径、`http:`、`https:` 或 `mailto:`。

### 键值行

相邻的 `字段 :: 内容` 行渲染为键值表，不需要结构块。`::` 两侧必须有空格；以 `- ` 开头的行是列表。

```md
事件定性 :: 凭证泄露导致的云侧异常操作。
影响范围 :: 写明受影响资产、账号、业务和时间范围。
```

### 图片

图片单独占一行：

```md
![证据截图](IR-20261008-01.assets/pasted/paste-20261008-143000-123456789.png)
![告警列表](IR-20261008-01.assets/alerts.png){size=md caption="图：告警列表"}
```

- 默认全宽（即 `{size=full}`），小图加 `{size=sm}` 或 `{size=md}`。
- `{caption="…"}` 在图片下方显示图注，分页不会把它与图片拆开。图注是纯文本，避免出现 `}`。粘贴图片自动插入的 `{caption=""}` 不需要时删掉。
- 图片地址只能是相对路径的本地文件或 base64 图片数据，`file:`、`smb:`、`blob:`、以 `//` 开头的地址和其他协议都会被拒绝。在 SIREN 中，本地图片还必须位于 `<报告名>.assets/` 目录内，见 [粘贴图片](/reports#粘贴图片)。

### 写作提示注释

HTML 注释只留在源文件（保存和下载 MD 时保留），不出现在预览、PDF 或 HTML 快照中。编辑器把闭合的注释折叠成一行，光标移入时展开。缺少闭合的 `-->` 时，后续内容都被当作注释跳过，编辑器会警告。

```md
<!-- 写作提示：没有证据时写“未观察到”，不要补猜测。 -->
```

### 模板占位

`[ 客户名称 ]` 这种内侧带空格的方括号是模板占位，原样渲染，但编辑器和屏幕预览会标出，**待填** 统计数量，导出 PDF 时会先确认。需要字面方括号时去掉内侧空格（`[ERROR]`）或放进行内代码。

## 结构块

结构块以 `::: 名称` 开头、单独一行 `:::` 结束，内容通常是 `字段 :: 内容` 行：

```md
::: callout
label :: 核心结论
headline :: 云侧凭证疑似泄露
body :: 攻击者使用访问密钥完成异常枚举与写入尝试。
:::
```

- 名称用小写 ASCII，未知名称会警告，内容原样保留。
- 围栏可以用三个以上冒号，结束围栏不短于开始围栏。

| 位置 | 结构块 |
| --- | --- |
| 根级：第一个 `##` 之前 | `cover-hero`、`cover-meta`、`rev` |
| 章节内 | `asset`、`recommendation`、`timeline`、`phase`、`attack`、`callout`、`html` |

根级结构块写在章节内不生效，并给出警告。

### cover-hero

封面主标题区。字段：`sev`（等级标签）、`title`（标题，用 `\n` 换行）、`title-en`（英文标题）。

```md
::: cover-hero
sev :: 严重等级 · 高危
title :: 安全事件\n应急响应报告
title-en :: Security Incident Response Report
:::
```

### cover-meta

封面信息表，用竖线表格书写。第一行可以是 `| k | v | sub |` 表头，每行依次为名称、值和可选副标题。

```md
::: cover-meta
| k | v | sub |
| 服务编号 | SIR-{date} | {sir-seq} · 首次交付 |
| 发布日期 | {date:slash-pad} | 版本 {version} |
:::
```

### rev

修订记录。第一行是表头，之后每行依次为日期、版本、描述、作者。

```md
::: rev
| 日期 | 版本 | 描述 | 作者 |
| {date:slash} | 1.0 | 新建：首次响应窗口的分析结论。 | 示例作者 |
:::
```

### asset

资产卡，每块一个排查对象，字段名自定。相邻的 `asset` 块合并为一组。

```md
::: asset
公网 IP :: 203.0.113.10
实例 ID :: i-demo0001
实例名称 :: prod-web-01
资产用途 :: 对外 Web 入口，暴露 80/443
:::
```

### recommendation

安全建议，每个阿里云产品或服务一块，相邻的 1 到 6 块组成编号清单。清单可在两项之间跨页，单项不拆分。

```md
::: recommendation priority=P1 type=product
name :: 云安全中心
risk :: 容器与主机运行时检测不足
reason :: 补齐异常行为检测与告警闭环能力。
action :: 在受影响集群启用防护并接入告警处置流程。
:::
```

- `priority` 必填，取 `P1`、`P2` 或 `P3`；`type` 必填，取 `product` 或 `service`。
- `name`、`risk`、`reason`、`action` 都必填。缺失或取值无效是解析错误，会阻止导出。
- 每个字段一两句话，保证单项放得进一页。不要写产品链接、价格或销售联系方式。

### timeline

时间线。节点写成 `- 时间 :: 事件`，末尾加 ` !` 强调；节点下方的普通行是说明文字。

```md
::: timeline
- T0 · 2026/10/08 09:12 :: 首次观察到异常访问密钥调用 !
  安全中心告警触发应急。
- T + 28 分钟 · 09:40 :: 完成受影响实例隔离
:::
```

### phase

响应阶段。`::: phase` 后写可选编号、标题和可选英文标题；第一个任务行之前的文字是阶段说明，之后用任务复选框列出动作，其后的非任务文字不显示。

```md
::: phase 抑制阶段 / Containment
隔离受影响实例并禁用泄露的访问密钥。
- [x] 安全组收紧至仅运维出口
- [/] 轮换受影响 AccessKey
- [ ] 复核 RAM 用户权限
:::
```

### attack

ATT&CK 矩阵。顶格 `- ` 行是战术，缩进 `- ` 行是技术，技术末尾加 ` !` 表示本次事件中观察到。

```md
::: attack
- 初始访问
  - 合法账户 !
  - 利用公开应用
- 执行
  - 命令解释器 !
:::
```

### callout

强调块，只支持 `label`、`headline`、`body`，其他行被忽略并警告。示例见本节开头。

### html

原始 HTML，只用于迁移旧报告或一次性布局。新报告优先用正文、图片、键值行和上面的结构块。正文中需要单独一行 `:::` 时，用更长的围栏包住外层：

```md
:::: html
<pre>
:::
</pre>
::::
```

## 写作建议

- 用 `##`、`###`、`####` 表达结构，不要用加粗文字模拟标题。
- 事件定性、影响范围、处置状态用键值行，关键时间线用 `timeline`，受影响资产用 `asset`。
- 没有证据时写“未观察到”或“无法确认”，不要补猜测。Dossier 自带模板的 HTML 注释中有更多写作提示。
